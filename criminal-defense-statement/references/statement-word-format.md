# 辩护词 Word 格式映射规范

## 一、适用范围

辩护词定稿后导出 Word 文档时使用。本规范只管版式，不管内容；内容仍受 SKILL.md 四类辩点结构、模块化 A/B 方案、"可以出了"红线约束。

## 二、标题层级映射

| 层级 | 内容定位 | Markdown 写法 | Word 字体字号 | 对齐/缩进 |
|------|----------|---------------|---------------|-----------|
| 大标题 | "辩护词"三字 / "第一部分""第二部分" | `# 辩护词` / `## 第一部分 事实与证据分析` | 三号黑体（16pt） | 居中 |
| 一级标题 | "一、""二、""三、" | `### 一、关于……的认定问题` | 四号黑体（14pt） | 首行缩进 2 字符 |
| 二级标题 | "（一）""（二）""（三）" | `#### （一）关于……的采信问题` | 四号楷体_GB2312（14pt） | 首行缩进 2 字符 |
| 三级标题 | "1.""2.""3." | `1. 第一次供述的取得程序`（普通段落加粗首句） | 小四仿宋_GB2312（12pt）加粗 | 首行缩进 2 字符 |
| 正文 | 论述段落 | 普通段落 | 四号仿宋_GB2312（14pt） | 首行缩进 2 字符 |

### 标题编号禁令清单

- 禁止一级标题跳号：不能出现"一、二、四"。
- 禁止二级标题跳号：不能出现"（一）（二）（四）"。
- 禁止用"第一""第二"替代"一、""二、"——前者是口语编号，辩护词用后者。
- 禁止默认结构里塞"第三部分"——一审案件只用首部 + 第一部分 + 第二部分 + 尾部。
- 禁止把"（一）"作为段落首句并入正文，必须独立成行。

## 三、字体字号映射表

辩护词版式跟民事代理词不同，本地惯例为**黑体标题 + 仿宋_GB2312 正文**，不用宋体作正文：

| 元素 | 字体 | 字号 | 备注 |
|------|------|------|------|
| 文档标题"辩护词" | 黑体 | 三号（16pt） | 加粗不需要，黑体本身够重 |
| 大标题（部分级） | 黑体 | 三号（16pt） | 居中 |
| 一级标题 | 黑体 | 四号（14pt） | 顶格或首行缩进 2 字符均可，全文统一 |
| 二级标题 | 楷体_GB2312 | 四号（14pt） | 与正文区分靠字体，不靠加粗 |
| 三级标题 | 仿宋_GB2312 | 小四（12pt） | 加粗 |
| 正文 | 仿宋_GB2312 | 四号（14pt） | 法院文书通用体例 |
| 法条引用段落 | 仿宋_GB2312 | 四号（14pt） | 与正文同体，前缩进 2 字符，可左缩进 1 字符凸显 |
| 页眉页脚 | 宋体 | 小五（9pt） | 案号 + 律所 + 页码 |

## 四、段落与行距

| 项目 | 参数 |
|------|------|
| 正文行距 | 1.5 倍行距，或固定值 27 磅（两套二选一，全文统一） |
| 段前段后 | 一级标题段前 0.5 行段后 0.5 行；其余 0 |
| 首行缩进 | 2 字符（约 0.74cm） |
| 法条引用块 | 整段左缩进 1 字符，首行再缩进 2 字符 |

## 五、页面与页码

| 项目 | 参数 |
|------|------|
| 纸张 | A4（21cm × 29.7cm） |
| 上下页边距 | 2.54cm |
| 左右页边距 | 3.17cm（装订线 0.5cm，左侧） |
| 页码位置 | 页脚居中，格式"第 X 页 共 Y 页" |
| 页眉 | 案号 + 被告人姓名 + "辩护词"，小五宋体 |

## 六、Word 导出禁止事项

导出前必须逐项检查，违规一条则退回重排：

- [ ] 不残留 Markdown 项目符号 `-`、`*`、`+`（须替换为中文"·"或编号列表）
- [ ] 不残留 Markdown 分隔线 `---`、`***`、`___`
- [ ] 不残留 Markdown 强调标记 `**加粗**`、`*斜体*`（须转为 Word 字体加粗或斜体）
- [ ] 不残留代码块 ``` 标记
- [ ] 不残留表格的 `|` 竖线（须转为 Word 原生表格）
- [ ] 不残留超链接的 `[]()` 语法
- [ ] 中文标点不得混入英文标点（特别是逗号、句号、括号）
- [ ] 数字与中文之间不强制空格，按法律文书惯例贴排
- [ ] 不出现 AI 味排版：不要"💡""⚠️"等 emoji，不要彩色色块

## 七、导出工作流

1. 在 Markdown 文件里按上表预留字体字号标注（可在 YAML frontmatter 或文末附"格式说明"块）
2. 用 `md2word` 或 `pandoc` 命令行导出 .docx
3. 在 Word 中手工微调：
   - 全选 → 行距 1.5 倍 / 固定 27 磅
   - 标题逐级套字体（黑体 / 楷体 / 仿宋）
   - 表格转原生，加边框
   - 页眉页脚录入案号与页码
4. 终检：用 Word 的"导航窗格"核对标题层级是否完整，无跳号、无错位

## 九、Word 中常见问题处理

| 问题 | 处理方法 |
|------|----------|
| 行距怎么都对不齐 | 全选 → 段落 → 取消"如果定义了文档网格，则对齐到网格" → 重新设置行距 |
| 首行缩进失效 | 不要用空格缩进，用"段落 → 首行缩进 → 2 字符"；从 Markdown 粘贴后须清格式 |
| 字体显示异常 | 仿宋_GB2312、楷体_GB2312 在 Mac 系统可能缺失，导出前在 Windows 端打开核验 |
| 表格跨页断裂 | 表格属性 → 行 → 取消"允许跨页断行"；重要表格设为"在各页顶端以标题行形式重复出现" |
| 页码不连续 | 检查是否插入了分节符；分节后须"链接到前一节"才能续编 |
| 标题前出现黑点 | 段落 → 换行和分页 → 取消"与下段同页""段中不分页"等勾选 |

## 十、Mac 与 Windows 兼容性

辩护词最终交付须考虑法院系统多在 Windows 环境，须注意：

- 字体：交付 .docx 前确认字体可在 Windows 显示；仿宋_GB2312、楷体_GB2312 为 Windows 自带，Mac 端如缺失需在 Word 中嵌入字体（Word → 选项 → 保存 → 将字体嵌入文件）。
- 文件名：避免特殊字符、空格、过长；建议命名 `09_辩护词_A基准版_被告人姓名_YYYYMMDD.docx`。
- 格式核验：导出后在 Windows 端用 Word 打开一次，逐页检查字体、行距、页码、表格是否完好。
- PDF 备份：法院系统有时只接受 PDF；导出 PDF 时务必用 Word 原生"另存为 PDF"，不用第三方转换工具，避免字体嵌入失败。

## 十一、多文件批量导出

案件交付物含 A 方案辩护词、B 方案应变模块、口袋版提纲等多份文件时，可批量导出：

```bash
# 用 md2word 批量转换（命令行工具，本机已装）
for f in 09_辩护词_A基准版_*.md 09_辩护词_B应变模块_*.md; do
  md2word "$f" --template 辩护词模板.dotx
done
```

注意：口袋版提纲不套辩护词模板，单独用紧凑模板导出。

## 十二、与 SKILL.md 的衔接

- 本规范只管版式；辩护词内容结构（首部、第一部分、第二部分、尾部）仍按 SKILL.md 执行。
- 模块化 A/B 方案导出时，A 方案、B 方案各出一份 Word 文件，文件名区分：`09_辩护词_A基准版_xxx.docx`、`09_辩护词_B应变模块_xxx.docx`。
- 口袋版提纲不套本规范，用紧凑排版，A5 双面打印，便于庭上手持。
- 最后陈述辅导材料按口语版排版，字号放大至小四，方便被告人庭审时阅读。
