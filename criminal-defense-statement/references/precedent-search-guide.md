# 类案检索与量刑计算指引

## 一、检索要素组合

### 1.1 四要素清单

| 要素 | 内容 | 必填 |
|------|------|------|
| 罪名 | 指控罪名全称（如"合同诈骗罪"，不用"诈骗"） | 必填 |
| 数额 / 情节区间 | "数额较大 / 巨大 / 特别巨大"，对应法定刑幅度 | 必填 |
| 从宽情节 | 自首、立功、从犯、未遂、退赃、谅解、认罪认罚 | 按本案实有 |
| 审理地域 | 受理法院所在省市，或上级法院 | 必填 |

### 1.2 组合策略

四要素叠加检索，命中率最高的顺序：

1. **罪名 + 数额区间 + 从宽情节 + 受理省份** → 同省类案
2. **罪名 + 数额区间 + 从宽情节** → 全国类案（补足数量）
3. **罪名 + 从宽情节 + 上级法院** → 上级法院倾向
4. **罪名 + 数额区间** → 法定刑幅度参考

### 1.3 检索要素填写示例

本案：合同诈骗罪，数额特别巨大，自首 + 退赃 + 谅解，H 省 X 市中级人民法院管辖。

```
罪名：合同诈骗罪
数额：数额特别巨大（起诉书认定 5,200,000 元）
情节：自首、退赃、被害人谅解、认罪认罚
地域：H 省X市；上级法院：H 省高级人民法院
```

## 二、检索结果使用规范

### 2.1 效力层级

| 层级 | 来源 | 效力 | 引用方式 |
|------|------|------|----------|
| 一 | 最高人民法院指导性案例 | 应当参照适用 | "依据最高人民法院第XX号指导性案例……" |
| 二 | 最高法公报案例 / 参考案例 | 应当参考 | "参考最高人民法院公报案例（XXX号）……" |
| 三 | 最高法典型案例 | 具有参考价值 | "最高人民法院公布的XXX典型案例中……" |
| 四 | 高级法院发布的参考性案例 | 本辖区参考 | "XX省高级人民法院发布的XXX参考案例……" |
| 五 | 普通生效判决 | 仅供思路参考 | 不直接作为依据，可作"司法实践中亦有……的裁判" |

### 2.2 引用要素

每个引用案例必须列明四项：

```
案号：（2023）X刑终XX号
法院：XX省XX市中级人民法院
裁判要旨：在合同诈骗数额特别巨大但被告人具有自首、全部退赃、取得谅解的案件中，可依法在法定刑幅度内大幅从轻，必要时适用缓刑。
裁判结果：有期徒刑三年，缓刑四年。
```

### 2.3 引用规范

- 引用案号用全称，不缩写。
- 裁判要旨必须是判决书原文表述，不归纳改写。
- 多个案例并列时，按效力层级从高到低排列。
- 区分"指导性案例应当参照"与"参考性案例可以参考"，措辞准确。

## 三、用于辩护主张的写法

### 3.1 "量刑过重"主张

```
依据《最高人民法院关于统一法律适用工作实施办法》关于类案检索的规定，辩护人检索了与本案件事实、情节相似的若干生效判决（详见下表）。在罪名相同、数额相当、从轻情节相近的情形下，类似案件的宣告刑多在有期徒刑三年至四年区间，部分适用缓刑。起诉书建议的有期徒刑七年明显偏重，恳请合议庭参考类案裁判，依法从轻处罚。

| 案号 | 数额（万元） | 情节 | 宣告刑 |
|------|-------------|------|--------|
| （2022）X刑初XX号 | 480 | 自首、退赃、谅解 | 三年，缓刑四年 |
| （2023）X刑终XX号 | 520 | 自首、退赃 | 三年六个月 |
```

### 3.2 "类案同判"主张

```
根据《最高人民法院关于完善统一法律适用工作机制的实施意见》，同级或上级法院在先裁判对类似案件具有参照意义。本辖区……法院审理的（2023）X刑初XX号案件，与本案在事实、数额、情节上高度相似，该案判处……。本案应保持裁判尺度统一，作出同等处罚。
```

### 3.3 用于定性辩护

```
最高人民法院第XXX号指导性案例明确：合同诈骗罪与民事欺诈的核心区别在于……本案情形与该指导性案例所列民事欺诈特征相符，与合同诈骗罪构成要件不符，应作无罪或变更罪名处理。
```

## 四、元典 MCP 作为本机主力检索工具

### 4.1 工具选择

本机配置的 `yuandian-law-search`（元典 MCP）是类案检索主力工具，调用方式：

- 触发词：查案例、检索案例、类案、判决、参考案例、指导性案例
- 自动调用：本辩护词生成前，若律师要求类案检索，应通过元典 MCP 完成

### 4.2 元典检索的操作建议

- 先用语义检索（`yuandian_case_vector_search`）做大范围召回
- 再用结构化过滤（案由、法院、地域、结案日期）缩小到目标范围
- 权威案例库优先（`dianxing: true`），指导性 / 公报 / 参考案例效力更高
- 检索结果须用案例详情接口（`yuandian_rh_case_details`）核验原文，不直接采信摘要

### 4.3 检索结果的留痕

辩护词定稿时，类案检索报告应作为附件单独存档：

```
{案件目录}/intermediate/09_类案检索报告_{YYYYMMDD}.md
```

含检索词、命中案例清单、被引用案例详情、未引用案例说明。

## 五、量刑计算参考公式

### 5.1 基本公式

```
预估宣告刑 = 基准刑 ×（1 ± 法定从重/从轻调节比例）± 酌定调节
```

### 5.2 操作步骤

| 步骤 | 操作 | 依据 |
|------|------|------|
| 1 | 确定基准刑 | 罪名、数额 / 情节对应法定刑幅度，取中值或下限 |
| 2 | 列举法定情节 | 自首、立功、从犯、未遂、未成年等，逐项标注调节比例 |
| 3 | 列举酌定情节 | 退赃、赔偿、谅解、认罪态度、初犯偶犯 |
| 4 | 计算综合区间 | 法定情节先叠加，再考虑酌定 |
| 5 | 标注法定底线 | 减轻处罚不得低于法定最低刑；从轻不得突破法定幅度 |

### 5.3 完整算例

> 罪名：合同诈骗罪，数额巨大，法定刑三年以上十年以下。
>
> 基准刑：取中值六年（72 个月）。
>
> 法定情节调节：
> - 自首：-20%（参照量刑指导意见）
> - 从犯：-30%
> - 退赃并取得谅解：-20%
> - 无前科（初犯偶犯）：-10%
>
> 综合调节：72 ×（1 - 0.20 - 0.30 - 0.20 - 0.10）= 72 × 0.20 = 14.4 个月。
>
> 法定底线：减轻处罚不得低于法定最低刑三年（36 个月）；本案属从轻而非减轻，故仍在三年以上。
>
> 预估宣告刑：有期徒刑三年至三年六个月；结合认罪认罚、社会危险性评估，可建议适用缓刑。

### 5.4 使用红线

- 本公式是参考算法，不是确定结论；律师须结合本案特殊性调整。
- 调节比例参考《最高人民法院、最高人民检察院关于常见犯罪的量刑指导意见》及各省实施细则。
- 辩护词中提及量刑计算时，须标注"参考算法，律师可调整"，避免给法庭留下"机械量刑"印象。
- 数额特别巨大、跨幅度量刑、数罪并罚等复杂情形，须分别计算后合并，不混在一个公式里。

## 六、与辩护词正文的衔接

- 类案检索报告作为附件，不在辩护词正文大段列案例。
- 辩护词正文引用案例不超过 3 个，精选最具效力的。
- 量刑计算可作为独立段落嵌入第二部分（法律分析），标题"五、关于量刑的建议"。
- 检索过程、完整案例清单、计算详算放在附件，正文只放结论。
