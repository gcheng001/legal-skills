# labor-exit-plan — 离职方案

## 工作定位

**职责**:为用工单位(HR/法务/外聘律师)提供**结构化离职方案**——覆盖八种路径(协商/严重违纪/竞聘/不胜任/客观情况/经济裁员/员工辞职/违法解除),逐路径判定 + 用户选定路径后给可执行 SOP。

**轨道**:顾问轨(轻状态:项目目录 `CLAUDE.md`+`LOG.md`+`client.md`+`deliverables/`)。

**必须确认**:是(出件前一次)。

**执行后 Hook**:否。

---

## 执行流程

### 步骤1 员工画像收集【完成判据:11项齐备+特殊保护命中】

询问并记录:
1. 姓名 / 岗位 / 部门 / 报告对象;
2. 入职日期 / 合同类型(固定/无固定/任务);
3. 累计工作年限;
4. 月工资结构(固定+绩效+奖金);
5. 工时制(标准/不定时/综合);
6. **特殊保护情形**(强制核查):三期(孕期/产期/哺乳期) / 工伤(医疗期/停工留薪期/职业病观察期)/ 病假医疗期 / 临近退休(连续工作满15年且距退休不足5年)/未成年工;
7. 现有证据:考核记录 / 违纪记录 / 培训记录 / 调岗记录 / 沟通记录;
8. 是否有协商可能(劳动者方意愿);
9. 是否有岗位空缺可转岗;
10. 用人单位近期经营状况(是否触发经济裁员);
11. 群体性案件风险评估(劳动者是否涉群体、与工会关系)。

**特殊保护命中原则**:
- 命中三期/工伤/医疗期/临近退休 → **强制标注"禁用路径"**(可能路径受限);
- 命中后**强制排除**部分路径(参见后表)。

### 步骤2 八路径可行性筛选【完成判据:八路径逐一有结论】

| # | 路径 | 法定条件 | 在本案是否满足 | 建议强度 |
|---|------|---------|---------------|---------|
| 1 | 协商解除 | 双方合意 | 需评估对方意愿 | 通用首推 |
| 2 | 严重违纪解除 | 制度合法+证据充分 | 看违纪事实与制度 | 命中证据则可用 |
| 3 | 竞聘上岗 | 程序合规+落聘≠解雇 | 看程序与考核 | 中等风险 |
| 4 | 不能胜任解除 | 培训/调岗+再考核 | 看四步闭环是否齐备 | **高门槛** |
| 5 | 客观情况解除 | 外部不可控+协商不成 | 看外部证据+协商记录 | 司法严苛,慎用 |
| 6 | 经济性裁员 | 20人或10% + 法定情形 + 程序 | 看人数/情形/程序 | 门槛最高 |
| 7 | 员工辞职 | 劳动者单方 | 不可控 | — |
| 8 | 违法解除 | (他人结果) | 反向 | **绝对避免** |

**特殊保护强制标注**:
- 三期/工伤/医疗期员工:**禁用**不胜任、客观情况变化、经济裁员;
- 临近退休员工:**禁用**经济裁员;
- 强保护期内严重违纪仍可能构成解除理由,但**须举证更严格**(课件3 P4 特殊群体保护缺位);

**完成判据**:八路径**全部**有"满足 / 可补强 / 不满足 / 禁用"四档判定;**即便用户只问"不胜任",也必须八路径全过**(plan 规定的完成判据)。

### 步骤3 可行路径对比表【完成判据:成本×败诉风险×周期×举证负担四维对比】

| 路径 | 成本(本案具体金额) | 败诉风险 | 周期 | 举证负担 |
|------|---------------------|---------|------|---------|
| 协商解除 | N+1 至 2N(可谈判) | 🟢 极低 | 短 | 中 |
| 严重违纪 | 0 | 🟡 中 | 短 | 重 |
| 竞聘上岗 | 0 | 🟡 中 | 中 | 中 |
| 不能胜任 | N + 1(N+1) | 🟥 高 | 中 | 极重 |
| 客观情况 | N | 🟥 高 | 中 | 极重 |
| 经济裁员 | N | 🟥 高 | 长 | 重 |
| 员工辞职 | 0 | 🟢 极低 | 30天 | 无 |
| 违法解除 | **2N** | 🔴 最高 | — | — |

**金额计算式**:对每条路径给出**本案具体金额计算**(月工资 × N 等);

⚠️ 强调"协商一致为上策"原则(参见八路径主题库)。

### 步骤4 用户选定路径 → 输出执行SOP【完成判据:六组件齐备】

用户选定路径后,输出 `deliverables/离职方案_XX_XX路径.md`,包含:

1. **路径决策**(所选路径与放弃的替代路径及原因);
2. **分阶段步骤**(每日/每周任务清单,如协商解除的"沟通次数+升级路径");
3. **证据固定清单**(每类证据的取证方式 + 取证时间表);
4. **时间线**(关键节点倒推,标注劳动法时限);
5. **话术要点**(与员工沟通的口径建议,**注意:任何口头承诺都可能成为呈堂证供**);
6. **失败预案**:若选定路径受阻,**如何"转争议轨"衔接(劳动OS总控联动)**:
   - 何种情形 → 转入 labor-intake;
   - 转入时需要交付的材料;
   - 保密与立场继承规则。

### 步骤5 文档包存与确认【完成判据:文档包完整】

包存 `deliverables/`。

⚠️ 文档内容仅为**HR/法务内部建议**,不得直接向员工出示;
- 出示/谈判稿/正式文书由 labor-contract-design(协议)或 labor-arbitration(争议)产出;
- 本skill产出文档建议加上"内部资料 - 不外传"水印。

## 红线

引用 `labor-os/references/redlines-labor.md`,本skill特有补充:
1. **八路径不绕过红线**:用户只问"不胜任",仍必须八路径全过;
2. **特殊保护禁用红线**:三期/工伤/医疗期/临近退休禁用路径**必须显式标注**,即便用户已有偏好;
3. **浙江口径标注红线**:浙江口径条款逐条标"依浙江口径";
4. **话术记录红线**:任何口头承诺都可能成为呈堂证供,话术要点中**避免绝对化承诺**;
5. **路径选择不替代用户红线**:**最终路径决策在用户**,AI只给评估。
