# 流拍抵债裁定送达即物权变动

## R — 原文 (Reading)

> “不动产的所有权自拍卖成交或者抵债裁定送达买受人或者承受人时起转移……该房产即属于建工集团所有……蓝星公司的该项申诉请求无法律依据。”
>
> — 李傲然，《执行法官视角下的保全与执行实务》，执行和解与以物抵债

---

## I — 方法论骨架 (Interpretation)

判断流拍抵债财产的权属，先看是否存在法院以物抵债裁定，再看裁定是否送达承受人。司法程序中的流拍抵债不同于当事人协议抵债：裁定送达时所有权即发生转移，后续未过户不否定权属变动。因此，另案在送达后实施的查封不能对抗已经取得的抵债权属。反过来，如果只是执行和解协议约定以物抵债，法院不得据此出具抵债裁定，权利人只能依协议另行主张或恢复原判决执行。两条轨道不能混用。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 蓝星公司以物抵债裁定效力争议案（转述，正式引用需回裁判文书核对）

- **问题**: 长春蓝星公司与长春建工集团的建设工程合同执行中，法院对房产作出以房抵债裁定并送达建工集团，但长期未办转移登记；蓝星公司主张未登记即不应生效。
- **方法论的使用**: 最高法院区分流拍抵债裁定与执行和解抵债协议，审查物权变动时点是否以登记为前提。
- **结论**: 抵债裁定送达建工集团时房产即归其所有，不以过户登记为生效条件。
- **结果**: 最高法院驳回蓝星公司申诉，确认房产归属建工集团。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 房产或其他不动产流拍后，债权人考虑接受以物抵债，需要判断权利何时取得。
2. 抵债裁定已送达但未过户，财产被另案查封、被执行人或案外人主张权属。
3. 当事人想用执行和解约定以房抵债，却误以为法院会出具可强制过户的抵债裁定。

### 语言信号 (用户的话里出现这些就应激活)

- “流拍后接受房子，什么时候算我的？”
- “抵债裁定送到了但没过户。”
- “和解说把房子抵给我，法院能不能出裁定？”

### 与相邻 skill 的区分

- 与 `participation-distribution-easy-rules` 的区别: 这里解决抵债财产的物权变动时点；后者解决其他债权人能否在分配方案送达前加入受偿。
- 与 `cross-court-case-funds-execution` 的区别: 这里处理不动产抵债权属；后者处理他院待发还案款的控制路径。

## E — 可执行步骤 (Execution)

1. **定性抵债轨道**
   - 完成标准: 判断是法院流拍后作出的以物抵债裁定，还是当事人执行和解协议中的抵债条款。
2. **核查送达与权属**
   - 完成标准: 找到裁定书、送达回证或送达时间；若为司法抵债裁定，确认所有权自送达时转移。
   - 判停条件: 若只是和解抵债条款，不主张裁定物权变动，转入恢复原判或另诉路径。
3. **处理登记与对抗关系**
   - 完成标准: 比对裁定送达时间与另案查封时间，明确权属优先关系，并推进过户或排除妨碍手续。
4. **设计后续风险控制**
   - 完成标准: 接受抵债前核算税费、占有状态和过户障碍；必要时在申请书中预留处置与登记安排。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 当事人仅达成买卖、借贷或和解中的协议抵债，没有法院流拍抵债裁定；不能套用“送达即转移”。
- 拍卖已经成交给第三人；此时按拍卖成交规则和过户义务分析，而不是流拍抵债。

### 作者在书中警告的失败模式

- 把流拍抵债裁定和执行和解抵债混为一谈，误以为和解抵债也能换来法院裁定和协助过户。
- 以“未登记=未生效”的日常认知否定已经送达的抵债裁定效力。

### 作者的盲点 / 时代局限

- 讲义聚焦不动产和最高法院监督案例，未覆盖动产抵债、税费负担争议或登记机关拒办的实操细节；具体财产类型应另行核对规则。

### 容易混淆的邻近方法论

- 司法抵债裁定的物权效力与协议抵债的债权效力：前者送达即转移所有权；后者只产生合同请求权，履行障碍需另寻救济。
