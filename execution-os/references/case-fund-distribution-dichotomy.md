# 房屋案款分配二分原则

## R — 原文 (Reading)

> "分配原则：'公司被执行按查封顺序，自然人被执行按比例参与分配'。"参与分配时点："以前：拍卖成交日、裁定过户日、案款分配日。现在：作出分配方案送达之前。……债权未得到清偿，执行程序便未终结，其他债权人仍可以在案款分配之前提出参与分配的申请。"
>
> — 李傲然，财产处置部分（房屋案款分配）及参与分配部分

---

## I — 方法论骨架 (Interpretation)

拍卖案款不足以清偿全部债权时，先看被执行人主体类型：
公司被执行→按查封顺序受偿，先封先得，不搞比例分配。
自然人被执行→进入参与分配逻辑，普通债权按比例受偿，优先债权（抵押权等）仍优先。
这个二分决定了债权人是否要抢首封、是否要及时申请参与分配。
自然人案件的参与分配时点已放宽：不再锚定拍卖成交或过户日，而是分配方案送达之前。
申请人不需要自己证明资不抵债——法院通过网络查控、终本、财产难以处置等事实证明即可。
操作上先确认主体类型，再决定策略：公司案件抢首封顺位；自然人案件确保在方案送达前提交申请。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 自然人唯一房产拍卖款的参与分配
- **问题**: 自然人被执行人的房产被拍卖，后来申报的债权人不确定能否分到案款。
- **方法论的使用**: 二分原则→自然人进入参与分配。时点规则→分配方案送达前申请即可，过户≠程序终结。
- **结论**: 后来申报的债权人在方案送达前申请，可按比例参与分配。
- **结果**: 最高法院2020年专业法官会议纪要明确"债权未得到清偿，执行程序便未终结"。

### 案例 2: 公司被执行人首封优先
- **问题**: 多个债权人查封了公司被执行人的不同财产，案款不足清偿全部债权。
- **方法论的使用**: 公司被执行→按查封顺序受偿，不走参与分配。
- **结论**: 首封债权人优先受偿，后续轮候查封人只能等剩余部分。
- **结果**: 债权人在公司案件中必须重视首封时机。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 房产拍卖成交后，多个债权人争案款，用户想知道分配规则。
2. 被执行人是自然人，用户想申请参与分配但不确定是否来得及。
3. 被执行人是公司，用户想确认首封是否意味着优先受偿。
4. 用户听到"过户了就不能参与分配了"，需要核实现行时点规则。

### 语言信号 (用户的话里出现这些就应激活)

- "案款怎么分"
- "参与分配"
- "按比例还是按顺序"
- "首封优先吗"
- "distribution of proceeds"

### 与相邻 skill 的区分

- 与 `auction-price-ladder-platform` 的区别: 本 skill 处理拍卖成交后的案款分配，后者处理拍卖环节的定价和平台。
- 与 `execution-case-status-triage` 的区别: 本 skill 关注案款在债权人之间怎么分，后者关注案件整体的程序状态。

## E — 可执行步骤 (Execution)

1. **确认被执行人主体类型**
   - 完成标准: 明确被执行人是公司还是自然人，套用对应分配逻辑。

2. **公司路径**
   - 完成标准: 确认查封顺序和时间，评估首封/轮候地位对受偿的影响。
   - 判停条件: 若被执行人是公司且已进入破产程序，转破产分配规则，本 skill 不再适用。

3. **自然人路径**
   - 完成标准: 确认是否存在在先优先债权（抵押权等），计算普通债权的比例受偿预期。

4. **把握参与分配时点**
   - 完成标准: 在分配方案送达之前向处置法院或原执行法院提交书面参与分配申请，保留提交凭证。

5. **资不抵债事实**
   - 完成标准: 收集网络查控结果、终本裁定、财产难以处置的证据材料作为辅助；申请人不负主动证明责任。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 被执行人已进入破产程序，应适用企业破产法的分配规则而非民事执行的参与分配。
- 用户问的是拍卖底价和平台合规性，应使用 `auction-price-ladder-platform`。

### 作者在书中警告的失败模式

- 把公司的查封顺序规则和自然人的参与分配规则混用，导致策略错误。
- 以为"过户了就终结了"，错过分配方案送达前的参与分配窗口。

### 作者的盲点 / 时代局限

- 讲义聚焦房屋案款场景，其他财产类型（车辆、股权）的分配逻辑可能类似但未逐一展开。
- 各地法院对参与分配的具体操作口径仍有差异。

### 容易混淆的邻近方法论

- 企业破产清算中的按比例清偿：虽然功能类似，但程序入口、法律依据和管理人角色完全不同。
