# 执行是地方性司法实践

## R — 原文 (Reading)

> "执行工作，一个地方性司法实践。""我的观点：看地方（司法实践），看大数据。比如北京，难办。"
>
> — 李傲然，开篇

---

## I — 方法论骨架

同一套执行规则在不同法院的落地差异很大：保全对口部门、保函是否附具、续封办理方式、限高解除口径、仲裁保全对口法院、财产处置节奏，都"看地方"。纸面规则只是起点，真正决定方案可行性的是受理法院的口径、惯例和近期案例大数据。方法论要求：方案落地前把"当地实践核实"当作必经步骤，而不是把外地经验或一般法条直接套用。核实对象包括对口部门、材料形式、时间预期、审查尺度；核实渠道包括当地律师、法院窗口、12368、仲裁委秘书处、公开裁判文书。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 仲裁保全递给哪家法院
- **问题**: 北京仲裁案件申请财产保全，直接向法院递交可能被退回。
- **方法论的使用**: 先问仲裁委秘书处对口法院，再核实当地法院分工口径。
- **结论**: 仲裁保全须经仲裁机构转交，对口法院按地方实践确定。
- **结果**: 材料走对通道，避免空跑。

### 案例 2: 保函是否需要附具
- **问题**: 不同法院对保全担保形式要求不一。
- **方法论的使用**: 提交前先核实当地法院是否接受保函及附加条件。
- **结论**: 担保方案按当地口径设计。
- **结果**: 避免因担保形式不符被驳回。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 异地执行或保全，不知道当地法院操作口径。
2. 仲裁保全，不确定对口法院和递交路径。
3. 向客户承诺执行周期或可行性前，需要校准预期。

### 语言信号 (用户的话里出现这些就应激活)

- "外地经验能直接用吗"
- "这个法院怎么操作"
- "北京/上海/深圳执行难不难"
- "仲裁保全递给哪家法院"

### 与相邻 skill 的区分

- 与 `liangbian-asset-ordering` 的区别: 那个解决"先封什么财产"，本 skill 解决"当地法院怎么操作"。
- 与 `execution-jurisdiction-two-anchors` 的区别: 那个解决法定管辖选择，本 skill 解决管辖确定后的地方实践核实。

## E — 可执行步骤 (Execution)

1. **识别地方敏感变量**
   - 完成标准: 列出本案涉及的对口部门、担保形式、续封方式、处置节奏等地方差异点。
2. **双渠道核实当地口径**
   - 完成标准: 至少两个独立渠道（当地律师/法院窗口/12368/仲裁委/公开文书）口径一致。
3. **固化核实结果**
   - 完成标准: 书面记录口径来源、时间、联系人，供团队复用。
4. **按当地口径调整方案**
   - 完成标准: 保全/执行方案的材料、路径、时间预期与当地实践一致。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 法条明文规定且无地方裁量空间的程序性事项（如查封期限"321"口诀），不需要再"看地方"。
- 用户只问法条原文，不涉及落地操作。

### 作者在书中警告的失败模式

- 套用外地经验导致材料被退回、周期误判、担保形式不符被驳回。

### 作者的盲点 / 时代局限

- 讲义以北京实践为主，其他地区口径仍需当地核实，不能反向套用北京经验。

### 容易混淆的邻近方法论

- 与"执行管辖法定二锚点"混淆：管辖是法定规则，地方实践是管辖确定后的操作口径。
