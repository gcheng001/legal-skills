# 执行管辖法定二锚点

## R — 原文 (Reading)

> "发生法律效力的民事判决、裁定，以及刑事判决、裁定中的财产部分，由第一审人民法院或者与第一审人民法院同级的被执行的财产所在地人民法院执行。……裁判要点：约定管辖不适用于执行案件管辖权的确定。"
>
> — 李傲然，执行管辖与时效部分（引镇雄县大银煤矿案）

---

## I — 方法论骨架 (Interpretation)

执行管辖和诉讼管辖是两套规则，合同里的约定管辖到了执行阶段就失效。
判断向哪个法院申请执行，只看两个法定锚点：
判决/裁定类：第一审法院，或与一审法院同级的被执行财产所在地法院。
仲裁裁决/公证债权文书类：被执行人住所地法院，或被执行财产所在地法院。
操作上先分清执行依据类型，再按对应锚点选法院。
选财产所在地法院时还要确认该法院对财产有实际控制和处置的便利，不是名义上沾边就行。
最常见的错误是把诉讼合同里的管辖条款直接带入执行申请，被不予受理后才意识到审执分离。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 镇雄大银煤矿执行复议案
- **问题**: 合同约定了管辖法院，但被执行财产在另一地，债权人不确定向哪个法院申请执行。
- **方法论的使用**: 最高法院明确裁判要点：约定管辖不适用于执行案件管辖权的确定，回到法定锚点判断。
- **结论**: 执行管辖不看合同约定，按一审法院或同级财产所在地法院确定。
- **结果**: 最高法院（2017）最高法执复6号确认了审执分离的管辖规则。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判决生效后准备申请执行，用户问"该向哪个法院提交"。
2. 合同约定了 A 地法院管辖，但财产全在 B 省，用户不确定去哪执行。
3. 仲裁裁决或公证债权文书需要执行，用户不确定管辖规则。
4. 被执行人财产分布在多地，用户需要选择最有利的执行法院。

## E — 可执行步骤 (Execution)

1. **识别执行依据类型**
   - 完成标准: 确认是判决/裁定/调解书，还是仲裁裁决/公证债权文书。

2. **套用对应锚点**
   - 完成标准: 判决裁定类→一审法院或同级财产所在地法院；仲裁公证类→被执行人住所地或财产所在地法院。

3. **排除约定管辖**
   - 完成标准: 确认合同中的管辖条款不影响执行管辖选择，不因约定而改变锚点。

4. **评估财产所在地法院的实际处置便利**
   - 完成标准: 若选择财产所在地法院，确认该法院对主要财产有查控和拍卖的实际操作能力。
   - 判停条件: 若一审法院和财产所在地法院是同一法院，无需选择，直接申请。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是诉讼阶段该约定哪个法院管辖，这属于诉讼策略，不是执行管辖。
- 用户问的是保全申请向哪个法院提交，保全法院选择有独立规则。

### 作者在书中警告的失败模式

- 把诉讼思维带入执行阶段，按合同约定管辖提交申请，被不予受理。

### 作者的盲点 / 时代局限

- 讲义未详细展开跨省执行的委托机制和实际效率差异，实操中财产所在地法院的执行意愿可能影响策略选择。

### 容易混淆的邻近方法论

- 诉讼管辖协议：执行阶段约定管辖失效是审执分离的核心体现，两者不能混用。
