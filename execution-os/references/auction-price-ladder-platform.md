# 网拍降价阶梯与平台合规

## R — 原文 (Reading)

> "起拍价不得低于评估价或者市价的百分之七十。……最高院精神，一句话概况，就是打折和降价。'先7折后8折，56%抵债'。"平台方面："最高人民法院已建立全国性网络服务提供者名单库……选择权在申请人eg淘宝、京东。不选择或选择不一，法院指定。7家之外，有风险，不建议。"
>
> — 李傲然，财产处置部分（网络司法拍卖）

---

## I — 方法论骨架 (Interpretation)

网拍定价按阶梯计算：
一拍起拍价≥评估价×70%。
二拍起拍价≥一拍保留价×80%（即评估价×56%）。
流拍抵债也按约56%计算。
快速心算公式：评估价×0.7=一拍底价；再×0.8=二拍底价。
平台选择看名单库：最高法院入围七家（淘宝、京东、人民法院诉讼资产网、公拍网、中拍协、工行融e购、北交所）。
申请人有优先选择权，不选或选不一致由法院指定。
名单外平台违法但不必然撤销已完成的拍卖——程序违法≠结果撤销，法院会权衡实质影响。
操作上先算底价预期管理，再确认平台合规性，最后准备异议策略。

## A1 — 书中的应用 (Past Application)

### 案例 1: 遵义新奥房产起拍价复议案
- **问题**: 被执行人对起拍价不服，认为过低，申请重新拍卖。
- **方法论的使用**: 重庆高院按评估价70%确定起拍价符合《网拍规定》第十条，新奥公司理解有误。
- **结论**: 最高法院驳回复议，维持原起拍价。
- **结果**: （2022）最高法执复55、56号确认70%底价的合法性。

### 案例 2: 香港中冠名单外平台拍卖案
- **问题**: 广州中院选择了不在最高法院七家名单库内的广州公共资源交易中心进行网拍。
- **方法论的使用**: 广东高院认定：选择名单外平台违反司法解释规定应予纠正，但本轮拍卖变卖已结束且未产生实质影响→无撤销必要。
- **结论**: 程序违法但不撤销已完成拍卖，后续拍卖须严格按名单库执行。
- **结果**: （2021）粤执复322号确立"违法≠必然撤销"的权衡规则。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户拿到评估报告，想知道一拍二拍的底价大概是多少。
2. 用户发现拍卖用了非名单库平台，想评估能否以此为由撤销拍卖。
3. 申请执行人需要行使平台选择权，不确定选哪家。
4. 用户需要预估流拍后的回收率来决定是否接受以物抵债。

### 语言信号 (用户的话里出现这些就应激活)

- "拍卖底价多少"
- "网拍降价"
- "7折8折"
- "拍卖平台合不合法"
- "auction price ladder"

### 与相邻 skill 的区分

- 与 `case-fund-distribution-dichotomy` 的区别: 本 skill 处理拍卖环节的定价和平台，后者处理拍卖成交后案款怎么分。
- 与 `execution-relief-three-tracks` 的区别: 本 skill 针对拍卖定价和平台的特定规则，后者是执行救济的整体分流框架。

## E — 可执行步骤 (Execution)

1. **获取评估价或市价**
   - 完成标准: 拿到评估报告或市场参考价，确认计价基准。

2. **计算降价阶梯**
   - 完成标准: 一拍底价=评估价×70%；二拍底价=一拍保留价×80%；流拍抵债价≈评估价×56%。

3. **确认平台合规性**
   - 完成标准: 核对拍卖平台是否在最高法院七家名单库内；申请人行使选择权或确认法院指定理由。

4. **评估异议可行性**
   - 完成标准: 若平台不合规，区分"程序违法"与"结果撤销"两个层面，评估实质影响和撤销可能性。
   - 判停条件: 若拍卖已完成且无实质影响，告知用户撤销难度大，重点转向后续程序合规。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是流拍后以物抵债裁定的物权变动效果，这属于另一套规则。
- 用户问的是被执行人以"估价过低"为由提异议，正确答案是市场检验而非估价标准。

### 作者在书中警告的失败模式

- 对底价预期过高，不接受二拍价格，导致流拍退回但债权并未消灭。
- 忽视平台合规性，事后才发现用了名单外平台，增加程序风险。

### 作者的盲点 / 时代局限

- 讲义提到《强制执行法》草案拟改为"先7折后6折，42%抵债"，正式立法通过后阶梯可能变化。
- 京牌小客车等特殊标的的拍卖规则（连牌带车、150%限价等）不在本框架内。

### 容易混淆的邻近方法论

- 询价异议的市场检验逻辑：被执行人以估价低为由提异议基本被驳回，因为最终成交价由市场检验而非估价决定。
