# 其他法院案款的第三人化执行

## R — 原文 (Reading)

> “其他法院可做‘第三人’，配合本院保全执行：冻结（暂停发还案款）+划拨（公对公）。”
>
> — 李傲然，《执行法官视角下的保全与执行实务》，其他法院作为第三人的协助执行

---

## I — 方法论骨架 (Interpretation)

核心是视角转换：法院不必只被看作程序机关，当它持有应当发还给被执行人的案款时，就是协助执行意义上的“第三人”。执行法院可以请持有款项的法院暂停发还，再公对公划拨；也可以让该法院把款发还到指定账户，同时提前冻结该账户，到账后扣划。使用时先确认资金来源、案号、发还对象和金额，再选择控制节点，避免款项已经进入被执行人自由账户后才行动。同一逻辑可类推到仲裁机构或其他机关应退还的费用。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 张三跨法院退款案款的冻结扣划方案（转述，正式引用需回裁判文书核对）

- **问题**: 张三是本院被执行人，又是朝阳法院案件的申请人，房地产开发商应向其退还60万元，退款可能进入朝阳法院账户。
- **方法论的使用**: 把朝阳法院识别为持有到期款项的第三人，设计两条控制路径：暂停发还并公对公划拨，或指定个人收款账户并提前冻结。
- **结论**: 其他法院的待发还案款可以通过协助执行控制，不必等待被执行人自行收款。
- **结果**: 讲义给出两种可行操作路径，未说明具体案件最终结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 被执行人在其他法院有胜诉案件，案款尚未发还。
2. 开发商、仲裁机构或行政机关应向被执行人退款，资金可能先进入法院或机构账户。
3. 常规账户查询无线索，但知道被执行人对他院或机构享有到期请求权。

### 语言信号 (用户的话里出现这些就应激活)

- “他在朝阳法院有案子要退钱。”
- “仲裁委说要给他退费。”
- “能不能直接划拨别的法院案款？”

### 与相邻 skill 的区分

- 与 `refusal-execution-offense-redlines` 的区别: 这里是合法控制他院待发还资金的程序路径；后者针对拆标的物或挪用已解封处置款的拒执行为。
- 与 `participation-distribution-easy-rules` 的区别: 这里处理本院对被执行人在他院债权的直接控制；后者处理多个债权人参与分配他人执行案款的资格与时点。

## E — 可执行步骤 (Execution)

1. **锁定资金关系**
   - 完成标准: 查明他院或机构的案号、被执行人的申请人身份、付款主体、应退金额和预计发还方式。
2. **选择控制节点**
   - 完成标准: 根据资金是否已到持有法院，确定“暂停发还+公对公划拨”或“指定账户+提前冻结”方案。
3. **发出协助执行请求**
   - 完成标准: 向持有款项的法院或机构说明本院执行依据、被执行人身份和请求内容，并留存送达或沟通记录。
   - 判停条件: 若款项已实际发还且无法追到指定账户，转入对被执行人账户的常规查控。
4. **跟进划拨与扣划**
   - 完成标准: 确认资金到账、办理扣划或分配手续，并回读案款状态。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只知道被执行人“可能有案子”，但无法提供法院、案号或资金来源；应先调查固定线索。
- 他院案款已经合法发还并混入被执行人账户，且无优先控制路径；此时按普通存款执行处理。

### 作者在书中警告的失败模式

- 把其他法院只当成程序机关，漏掉其“持有到期款项的第三人”身份。
- 等待款项发还完成后再查账户，错过暂停发还或提前冻结的窗口。

### 作者的盲点 / 时代局限

- 讲者以“我院—张三—朝阳法院”举例，未展开不同法院之间案款协查的实际审批时长、跨省协作和异议处理差异；落地前需与持有款项法院核实口径。

### 容易混淆的邻近方法论

- 跨法院案款协助与参与分配：前者是本院直接控制被执行人对外的到期资金；后者是被执行人财产被处置后，其他债权人申请加入受偿。
