# 拒执罪两类高危行为红线

## R — 原文 (Reading)

> “孙才恩完全有能力执行生效判决，交付房产，但其不仅拒绝、阻碍执行，甚至将房屋拆除……直接导致标的物灭失，生效判决无法执行……被判处有期徒刑一年。”
>
> — 李傲然，《执行法官视角下的保全与执行实务》，拒不执行判决、裁定罪示例

---

## I — 方法论骨架 (Interpretation)

这个方法把拒执风险从抽象的“拒不执行”落到两类可识别行为：一是被执行人有履行能力，却拆毁、改建或以其他方式使特定执行标的物灭失；二是经协商申请解封后出售财产，却把本应清偿债务的处置款挪作他用。判断时先看履行能力与生效判决义务，再看行为是否直接阻断执行，最后固定行为与结果之间的证据链。对代理人来说，它同时提供攻防两端动作：追责方尽早控制标的物、保存协商与资金流向证据；处置方在解封变现前用账户、金额、时间和用途锁定资金。

## A1 — 书中的应用 (Past Application)

### 案例 1: 孙才恩拆毁待交付房屋拒执案（转述，正式引用需回裁判文书核对）

- **问题**: 孙才恩负有返还房屋义务且有履行能力，但拒绝交付并擅自拆房另建新房。
- **方法论的使用**: 法院围绕履行能力、抗拒执行的主观故意和标的物灭失后果审查行为是否构成拒执罪。
- **结论**: 拆毁判决标的物并致判决无法执行，属于情节严重的拒执行为。
- **结果**: 孙才恩被判处有期徒刑一年。

### 案例 2: 王开峰解封售房挪用房款拒执案（转述，正式引用需回裁判文书核对）

- **问题**: 王开峰名下房产已被查封；经协商请求解封出售后，售房款未用于履行生效判决。
- **方法论的使用**: 法院把“解封是为了变现清偿”作为前提，审查处置款是否被挪用及判决是否因此无法执行。
- **结论**: 解封后挪用房款，使生效判决不能执行，构成拒执罪。
- **结果**: 王开峰被判处有期徒刑一年。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判决要求返还房屋、车辆或特定物，被执行人出现拆除、改建、隐藏、转让迹象。
2. 被执行人请求解封房产、车辆等财产出售，申请人要评估售房款是否会逃逸。
3. 已有拒执线索，需要整理移送材料、刑事控告路径或民事执行与刑事责任的衔接。

### 语言信号 (用户的话里出现这些就应激活)

- “他有能力还，却把房子拆了。”
- “法院解封后他把卖房款花掉了。”
- “这种情况能不能告拒执罪？”

### 与相邻 skill 的区分

- 与 `cross-court-case-funds-execution` 的区别: 这里处理被执行人破坏执行或挪用处置款的刑事红线；后者处理他院待发还案款的协助控制路径。
- 与 `execution-offset-ruling-property-transfer` 的区别: 这里关注拒执行为和刑责；后者关注流拍抵债裁定送达后的物权变动。

## E — 可执行步骤 (Execution)

1. **固定义务与履行能力**
   - 完成标准: 摘出生效判决义务、履行期限和被执行人可供履行的财产或行为能力。
2. **识别红线行为**
   - 完成标准: 判断属于拆毁标的物致执行不能，还是解封处置后挪用款项；记录时间、地点、行为和后果。
   - 判停条件: 若无履行能力且行为未致判决无法执行，转入普通执行或民事救济分析。
3. **保全证据并选择路径**
   - 完成标准: 收集照片、视频、登记变更、协商记录、解封申请、收款账户和资金流水；需要刑事追责的，整理拒执线索并评估移送或控告材料。
4. **设置处置资金控制**
   - 完成标准: 解封出售前明确收款账户、优先清偿金额、付款节点，必要时采用监管账户或书面承诺。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 被执行人确实丧失履行能力，只是暂未足额清偿；此时应评估执行措施和和解，而不是直接套用拒执罪。
- 争议仍在一审、二审或仲裁中，生效判决尚未形成；拒执罪以拒不执行生效判决、裁定为前提。

### 作者在书中警告的失败模式

- 只把拒执理解为公开对抗，忽视拆毁标的物和挪用解封处置款这两类更具体的行为红线。
- 同意解封出售时没有锁定收款账户和资金用途，导致款项被挪后难以回转。

### 作者的盲点 / 时代局限

- 讲义以典型案例展示入罪逻辑，未展开各地公安立案标准、证据门槛和“自诉与公诉”衔接差异；跨地区使用前应核实当地实践。

### 容易混淆的邻近方法论

- 拒执罪与普通拒不配合：前者要求有能力履行且情节严重，通常直接阻断生效判决执行；后者可能只引发罚款、拘留或其他强制措施。
