# 保全财产"两便原则"排序

## R — 原文 (Reading)

> "保全，按照'两便原则'排序。何谓'两便原则'？一是方便保全小组动手；二是方便未来执行变现。前：银行卡是第一保全执行措施。房产、车辆放在第二位。股票优先。国企机关事业单位公积金优先。后：有限公司股权、域名、靓号、第三人到期债权。"
>
> — 李傲然，保全部分（保全策略）

---

## I — 方法论骨架 (Interpretation)

选择保全对象时，不要按名义价值高低排，而要按两个维度同时打分：
一是法院能否低成本控制（方便保全小组动手），二是财产能否高效变现（方便未来执行变现）。
两个维度都高的财产排前面，都低的排后面，一高一低的看综合效率。
银行卡、股票、公积金等线上可冻结、变现快的财产排第一梯队。
房产、车辆虽然价值大但控制成本高、变现周期长，排第二梯队。
有限公司股权、域名、第三人债权等难评估、难拍卖的财产排最后。
这个框架把"能查到"和"能换成钱"拆开评估，避免只盯名义价值高的资产而浪费时间窗口。

## A1 — 书中的应用 (Past Application)

### 案例 1: 首次保全谈话的排序决策
- **问题**: 律师在起诉立案阶段同时发现被执行人有房产、银行存款、有限公司股权，保全额度有限，需要决定申请顺序。
- **方法论的使用**: 按"两便原则"打分：银行卡线上可冻、即时生效排第一；房产虽价值大但需要线下查封、后续拍卖周期长排第二；股权难评估、难变现排最后。
- **结论**: 保全申请书按银行卡→房产→股权的顺序列明保全对象。
- **结果**: 银行卡即时冻结形成压力，房产查封作为兜底，股权因变现困难未被优先申请。

### 案例 2: 反例——保全对象排序错误
- **问题**: 律师只盯着被执行人的商铺（名义价值高），忽略了被执行人持有的上市公司股票。
- **方法论的使用**: 用两便原则重新评估：上市公司股票线上可冻结、变现效率远高于商铺。
- **结论**: 应优先冻结股票而非商铺。
- **结果**: 排序错误导致错过了冻结股票的窗口期。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 起诉前准备财产保全申请，发现被执行人有多项财产但保全额度有限，需要决定申请哪些。
2. 首次保全谈话前，律师需要向法官说明为什么选择这些保全对象。
3. 执行立案后发现多项可执行财产，需要决定先申请执行哪一项。
4. 被执行人同时有易变现和难变现财产，用户在纠结是否值得花精力去封难变现的。

### 语言信号 (用户的话里出现这些就应激活)

- "先封哪个财产"
- "保全排序"
- "这些财产哪个优先"
- "保全策略怎么定"
- "asset ordering"

### 与相邻 skill 的区分

- 与 `duobao-renewal-management` 的区别: 本 skill 决定"封什么"，后者决定"封了之后怎么保住不脱保"。
- 与 `case-fund-distribution-dichotomy` 的区别: 本 skill 是保全前的选择，后者是变现后案款怎么分。

## E — 可执行步骤 (Execution)

1. **盘点可查控财产清单**
   - 完成标准: 列出被执行人名下所有已知财产，标注类型（存款/房产/车辆/股权/应收款等）。

2. **按两维打分**
   - 完成标准: 每项财产标注控制难度（线上/线下、是否需协助）和变现效率（拍卖周期、流拍风险）。

3. **排序并写入保全申请**
   - 完成标准: 产出排序清单：银行卡/股票/公积金 → 房产/车辆 → 股权/域名/第三人债权，并写入保全申请书。
   - 判停条件: 若保全额度足以覆盖全部财产，则无需排序，全部申请即可。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 案款已进入分配阶段，此时应使用 `case-fund-distribution-dichotomy` 判断受偿顺序。
- 用户问的是"封了之后怎么续期"，应使用 `duobao-renewal-management`。

### 作者在书中警告的失败模式

- 只看名义价值不看变现效率，导致封了一堆卖不动的资产，错过了冻结流动性财产的窗口。

### 作者的盲点 / 时代局限

- 讲义基于 2024 年北京法院实践，各地法院对"方便动手"的判断可能不同，尤其是异地财产的委托执行效率。

### 容易混淆的邻近方法论

- 执行顺位规则：本 skill 是申请人的策略选择，不等于法律上的受偿顺位。
