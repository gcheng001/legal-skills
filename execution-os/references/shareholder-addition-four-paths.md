# 股东追加四路径

## R — 原文 (Reading)

> "（1）【公司未经清算即注销登记】+【公司终本】=【公司股东】承担连带责任。……（2）【公司吊销】+【公司终本】+【15天不成立清算组】=【公司股东】承担连带责任。（3）【公司终本】+【公司未实缴出资】=未出资股东在【出资额范围内】承担【补充清偿责任】。（4）【一人公司】+【公司终本】=执行追加【一人股东】为被执行人。"
>
> — 李傲然，变更追加部分（常见股东追加路径）

---

## I — 方法论骨架 (Interpretation)

公司终本后想追股东，先梳理公司的事实状态，再匹配四条路径之一：
路径一：公司没清算就注销了→股东对全部债务承担连带责任，不管出资有没有实缴。
路径二：公司被吊销执照后15天内没成立清算组→股东连带责任。
路径三：公司有未实缴出资→未出资股东只在出资额范围内承担补充清偿责任。
路径四：一人公司→股东要自证公司财产独立于个人财产，证不出来就连带。
四条路径的责任范围不同（连带 vs 补充清偿），举证责任也不同（尤其一人公司是举证责任倒置）。
操作上先查工商状态（注销/吊销/存续），再查出资情况，最后匹配路径。

## A1 — 书中的应用 (Past Application)

### 案例 1: 个人独资企业追加投资人
- **问题**: 北京国坤建筑机械租赁中心（个人独资企业）不能清偿债务，申请执行人想追加投资人梁某1。
- **方法论的使用**: 个人独资企业不能清偿→按《变更追加规定》第13条追加出资人。法院查明梁某1是纠纷发生时的投资人，追加成立；陈某、汪某不是纠纷发生时的投资人，追加被驳。
- **结论**: 追加梁某1为被执行人，对未履行部分承担连带清偿责任。
- **结果**: 北京一中院（2019）京01执复204号支持追加梁某1，驳回追加陈某、汪某。

### 案例 2: 一人公司股东自证财产独立
- **问题**: 一人公司终本后，债权人申请追加股东，股东拿出自己做的审计报告抗辩。
- **方法论的使用**: 一人公司路径的举证责任倒置——股东需证明公司财产独立，单方报告效力存疑但完整审计可能被采信。
- **结论**: 举证不能则股东承担连带责任。
- **结果**: 法院按举证是否充分判断是否追加。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司被执行人终本后，用户想追加股东继续追债。
2. 用户发现公司被吊销或注销，想确认能否追股东。
3. 用户面对一人公司被执行人，想知道能否直接追股东个人。
4. 用户需要判断追到股东后能拿多少钱（连带还是补充清偿）。

### 语言信号 (用户的话里出现这些就应激活)

- 与 `execution-case-status-triage` 的区别: 本 skill 要求公司已终本作为前提，后者判断案件是否确实处于终本状态。

## E — 可执行步骤 (Execution)

1. **确认公司执行状态**
   - 完成标准: 拿到终本裁定书或通过执行信息系统确认公司案件已终本。
   - 判停条件: 若公司案件尚未终本，等待终本后再操作。

2. **查工商状态**
   - 完成标准: 通过企业信用公示系统查公司状态（注销/吊销/存续），确认是否存在未经清算注销或吊销后未清算的事实。

3. **查出资情况**
   - 完成标准: 调取公司章程、工商档案，确认股东认缴额与实缴额，识别未实缴股东。

4. **匹配路径并确定责任范围**
   - 完成标准: 按事实组合匹配四路径之一，明确主张连带责任还是补充清偿责任，以及对应的举证重点。

5. **提交追加申请**
   - 完成标准: 向执行法院提交书面追加申请，附终本裁定、工商档案、出资证明等证据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 公司尚未终本，追加申请可能被以"不在执行过程中"为由驳回。
- 拟追加对象不是公司股东（如配偶、关联方），应使用 `execution-addition-statutory-principle` 判断。

### 作者在书中警告的失败模式

- 混淆连带责任和补充清偿责任的范围差异，导致预期错误。
- 一人公司股东仅提交单方审计报告，未达到"证明财产独立"的举证标准。

### 作者的盲点 / 时代局限

- 讲义聚焦公司终本后的追加，未覆盖公司尚在执行中但发现股东抽逃出资等情形。
- 2014年公司法修改后认缴制下的出资加速到期问题仍在发展。

### 容易混淆的邻近方法论

- 公司法人格否认（刺破面纱）：那是审判程序中的制度，本 skill 是执行程序中的追加，程序和标准不同。
