# 空壳股权拍卖前置商业判断

## R — 原文 (Reading)

> "多数情况，有限责任公司股权，公司账上没流水、没财产、空壳、财务报表丢失。这类案件，执行法官一般不愿意拍卖，无意义。一是公司人去楼空没有财产报表无法评估。二是评估成功后无人竞买，浪费司法资源。三是申请人不愿预交评估费。四是评估公司拒绝评估。怎么办？答案：找到买受人，申请人垫评估费。"
>
> — 李傲然，股权执行

---

## I — 方法论骨架

"有股权就有价值"是直觉陷阱。空壳公司股权拍卖面临四障碍：无法评估（无报表）、无人竞买、申请人不愿垫评估费、评估公司拒评。正确顺序是先做商业可行性判断——找到潜在买受人并由申请人愿意垫付评估费，再推动司法拍卖；找不到买受人时转向股东追加等其他路径。方法论是把交易思维前置到司法程序之前：先确认市场有人接，再启动评估和拍卖，避免司法资源浪费和程序空转。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 亏损科技公司30%股权
- **问题**: 要不要申请拍卖。
- **方法论的使用**: 前置判断——先调研是否有产业买家愿意接。
- **结论**: 无买家则转向股东追加路径。
- **结果**: 避免四障碍导致的程序空转。

### 案例 2: 找到买受人后的推进
- **问题**: 有意向买家但公司无报表无法评估。
- **方法论的使用**: 申请人垫付评估费，与评估公司沟通可行性。
- **结论**: 先锁定需求侧再解决供给侧障碍。
- **结果**: 拍卖具备商业基础后启动。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 被执行人持有账上无流水、无财产的空壳公司股权。
2. 考虑申请拍卖某笔股权但不确定商业价值。
3. 评估公司拒评或无人竞买的风险需要预判。

### 语言信号 (用户的话里出现这些就应激活)

- "这个股权值钱吗"
- "能不能拍卖他的股份"
- "没人买怎么办"
- "评估费谁出"

### 与相邻 skill 的区分

- 与 `shareholder-addition-four-paths` 的区别: 那个是追加股东为被执行人的法定路径，本 skill 是处置股权前的商业可行性判断；无买家时应转向追加路径。
- 与 `auction-price-ladder-platform` 的区别: 那个解决定价阶梯和平台合规，本 skill 解决"要不要启动拍卖"的前置决策。

## E — 可执行步骤 (Execution)

1. **识别空壳特征**
   - 完成标准: 核查公司流水、财产、报表状态，确认是否落入四障碍场景。
2. **调研潜在买受人**
   - 完成标准: 明确产业买家、竞争对手、关联方等可能接盘方及其意愿。
3. **落实费用承担**
   - 完成标准: 申请人对垫付评估费形成书面决定。
4. **决策路径**
   - 完成标准: 有买家+愿垫费则推动拍卖；否则转向股东追加等替代路径并记录理由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 公司有实际经营、财务报表完整，直接走正常评估拍卖。
- 用户问的是股东追加的法定条件，不是拍卖可行性。

### 作者在书中警告的失败模式

- 直觉性申请拍卖，遭遇四障碍后程序空转、费用沉没。

### 作者的盲点 / 时代局限

- 讲义未展开强制清算、破产等替代路径的衔接细节，需另行核实。

### 容易混淆的邻近方法论

- 与"网拍降价阶梯"混淆：降价阶梯解决已启动拍卖的定价问题，本 skill 是启动前的商业判断，两者作用阶段不同。
