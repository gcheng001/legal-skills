## 1. 劳动新增红线

### 1.1 裁判者三红线(争议轨立场=adjudicator 专属)

#### 红线1.1.1 结论先行禁令
- 🟥**场景**:立场为裁判者(高澄以仲裁员/法官身份办案)时;
- 🟥**要求**:**AI 严禁先给裁判结论**;
- 🟥**正确流程**:① 输出焦点归纳 + 庭审发问提纲 + 证据三性分析;② **停下**,口头/书面提示用户"请逐项定调:支持/部分支持/驳回";③ 用户定调前**禁止起草裁决书**;④ 用户定调后,按用户结论组织"本委认为"逐焦点说理 + 裁决主文骨架;
- 🟥**Hard Fail**:任何"AI主动预判支持/不支持"的输出 = Hard Fail,需重新回到三步流程。

#### 红线1.1.2 利益冲突自检
- 🟥**场景**:立场为裁判者;
- 🟥**要求**:接案时核对当事人是否与高澄代理业务/顾问单位关联;
- 🟥**有则**:立即提示用户**回避**;`labor-os-state.json.conflict_check.result=need_recusal`;不再向顾问轨知识沉淀推送本案材料;
- 🟥**无则**:记 `clear` 继续。

#### 红线1.1.3 保密隔离
- 🟥**场景**:立场为裁判者;
- 🟥**要求**:裁判案件材料与分析**禁止**流入顾问轨知识沉淀与经验卡;
- 🟥**实现**:laboration-output 仅在 `intermediate/劳动覆盖层/L{1-4}/` 路径内,**不得**写入 `~/.claude/skills/*/knowledge/` 或任何经验库。

---

### 1.2 时效红线(争议轨通用)

- 🟥**法定时效已过**或**30 日内届满**的请求项 → **首屏红字预警**,不得埋在正文;
- 🟥**首屏文本必须含**:
  - 各项请求时效届满日;
  - 剩余天数倒计时;
  - 失权后果;
- 🟥**中断/中止事由**:核查后写入正文,但不能取代首屏预警。

---

### 1.3 属地红线(全程)

- 🟥**任何引用浙江口径的结论**必须**逐条显式标"依浙江口径"**;
- 🟥**未标注不得交接**给下游 skill / 不得入卷;
- 🟥**跨省适配时**:
  - 显式询问:是哪个省/直辖市;
  - 切换知识库条目到该省口径(目前仅浙江本地化完成,**其他省暂未本地化,需先与高澄确认可用性,不得擅自套用**)。

---

### 1.4 权威分级红线(全程)

- 🟥**讲师经验**、**地方裁判口径**等**不得**出现在仲裁/诉讼文书的**"法律依据"**位置;
- 🟥**正确做法**:
  - 法律依据段:只引国家法律法规与司法解释;
  - 代理意见段:可以引地方裁判口径并标"依浙江/某省裁判口径";
  - 实务观点:必须显式标注"⚠️ 实务观点,非法律依据";
- 🟥**严打混淆**:任何"讲师经验实质内容升格为法律依据" = Hard Fail。

---

### 1.5 称谓红线(争议轨全程)

| 阶段 | 申请人侧 | 被申请人侧 | 备注 |
|------|---------|-----------|------|
| **仲裁阶段**全文 | 申请人 | 被申请人 | 包含申请书、答辩书、证据目录、仲裁文书 |
| **诉讼阶段**(L3及以后) | 原告 | 被告 | 包含起诉状、上诉状、答辩状、判决书 |
| **执行阶段** | 申请执行人 | 被执行人 | 包含执行申请书、限高/失信申请 |
| **裁判者内部** | 一方 | 另一方 | 在说理段落避免当事人姓名反复,可用"申请人"指代 |

- 🟥**禁止在同一份文书内混合称谓**(如先"申请人"突然变成"原告");
- 🟥**案件目录命名**沿用 case-os"原告九步法/被告九步法"(**申请人≈原告位**,**被申请人≈被告位**);
- 🟥**劳动OS内部 state.json / deadlines 等结构化字段**:
  - 立场(stance):claimant / respondent / adjudicator(英文固定);
  - 当事人姓名:作为 `case_meta.parties` 的 JSON 值保留,不混入称谓混淆。

### 1.6 解除程序红线(L4 离职方案与 L2 仲裁共用)

- 🟥**任何**单方解除必须**核查下列程序**,缺一项 = 违法解除风险:
  - 工会通知(用人单位侧单方解除**必须**事先通知工会);
  - 30 日提前书面通知 / 代通知金(N+1 中的 +1);
  - 工资 **5 日内结清**(浙江);
  - 离职证明出具;
  - 社保减员 / 档案转移;
- 🟥**不胜任解除**:四步闭环(初次不胜任 → 培训/调岗 → 再次不胜任 → 法定解除程序),缺一不可;
- 🟥**特殊群体(三期/工伤/医疗期)**禁用大部分单方解除路径(详见离职八路径主题库);
- 🟥**经济裁员**:20人/10%门槛 + 法定情形 + 三步程序(30天说明 + 听取意见 + 行政报告),缺一不可。

---

### 1.7 证据红线(争议轨全程)

- 🟥**录音录像证据**必须刻光盘(写明证据几),附文字稿;
- 🟥**电子数据**(电子考勤、钉钉记录、邮件等)需出示**原始载体或公证书**(浙江实务严于全国);
- 🟥**证明目的以客观陈述为主**,禁止放主观结论(如"证明原告系被迫离职" → 改为客观证据+引证);
- 🟥**录音证据**:在不侵犯隐私/不违反法律法规的前提下可作为证据(课件4 P15)。

---

### 1.8 转轨衔接红线(争议轨)

- 🟥**从仲裁转诉讼**(L2 → L3):
  - **称谓必须切换**(申请人 → 原告 / 被申请人 → 被告);
  - 15 日起诉窗口**首屏倒计时**;
  - 时效抗辩跨阶段失权**显著提示**(司法解释二第 20 条);
- 🟥**从诉讼转执行**(L3 → L4):
  - 2 年执行申请期限**首屏倒计时**;
  - 已部分履行核实后,**不得重复申请**;
- 🟥**md2word 操作**:仅用户"可以出了"的明确确认后触发。
