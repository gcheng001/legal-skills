## Z1 《劳动争议解答(四)》三:年终奖

- 权威层级: 地方裁判口径
- 属地: zhejiang
- 来源: 课件1 P32
- 依据: 浙江省高院/省仲裁院《劳动争议解答(四)》三
- verified: pending

### 原文(摘录)
> 用人单位依法制定的规章制度规定,在发放年度绩效奖金时双方已解除或终止劳动合同的,不予发放年度绩效奖金。该规定是否有效?
> **答**:该规章制度未违反法律、法规的强制性规定,**应属合法有效**。在发放年度绩效奖金时双方已解除或终止劳动合同,劳动者请求用人单位支付年度绩效奖金的,**一般不予支持**。

### 实务要点
- 💡 实务要点:**可通过规章制度约定离职不发年终奖**;
- ⚠️ 必须经过**民主程序制定 + 向员工公示**;
- "应属合法有效" + "**一般不予支持**" = 浙江口径偏用人单位,但劳动者仍可基于"显失公平"等理由挑战。

## Z2 《劳动争议解答(六)》

### Z2.1 第3条:企业罚款条款无效

- 权威层级: 地方裁判口径
- 属地: zhejiang
- 来源: 课件2 P12
- 依据: 浙江省高院/省仲裁院《劳动争议解答(六)》第3条
- verified: pending

> 用人单位在规章制度中规定若劳动者工作考核不合格或违反单位规定给予一定金额的罚款,该规定是否有效?
> **答**:法律并未赋予用人单位对职工进行罚款的权力,用人单位规章制度中规定可以对劳动者进行罚款,此类条款**因缺乏法律依据而应认定无效**。
> **但若此类条款属于扣减考核奖金或者绩效工资等需经考核后确定金额的工资项目的,则不受前款约束。**

### 实务要点
- 🟥 **罚款条款 = 高风险,无效**;
- 🟢 **考核扣减 = 合法**(但需制度合法 + 实际履行考核);
- 改造路径:变"罚款"为"全勤奖/绩效工资扣减";
- 详见[考勤制度坑点清单]坑1与坑2。

### Z2.2 第5条:请假未批 ≠ 旷工

- 权威层级: 地方裁判口径
- 属地: zhejiang
- 来源: 课件2 P21
- 依据: 浙江省高院/省仲裁院《劳动争议解答(六)》第5条
- verified: pending

> 用人单位规章制度规定"员工请病假需报经公司批准同意,并履行请假手续后方可休病假,否则视为旷工",劳动者请病假,但未获用人单位批准而未上班**能否算旷工**?
> **答**:劳动者已经提交请病假手续,在未获批准的情况下未正常上班,**一般不属于旷工**。同时应根据**劳动者疾病情况、请假时间长短、未正常上班事由以及用人单位主张的未批准事由是否充分**等综合判断。

### 实务要点
- 🟥 制度把"未获批=旷工"无差别挂钩 → **违法解除高发**;
- 应对:制度需明确"紧急情况下口头+书面补办"路径,综合判断条款。

## Z3 《劳动争议解答(七)》(2025.12发布)

- 权威层级: 地方裁判口径
- 属地: zhejiang
- 来源: 课件3 P13
- 依据: 浙江省劳动人事争议解答参考(七)
- verified: pending

### 关键提示
> 文件再次强调,在符合法定订立无固定期限劳动合同的条件下,**合同续订的最终选择权完全归属于劳动者**。用人单位**不得**利用优势地位,通过合同期限设置、岗位调整等方式规避法定义务,否则将承担**支付赔偿金**的法律后果。

### 与全国一般口径的关系
- 与全国《劳动合同法》第十四条 + 第三次修订口径一致;
- 浙江口径进一步强调"利用合同期限规避"情形的赔偿金风险;
- ⚠️ 实务观点,非法律依据:即便劳动者未"明确"拒绝续订,只要满足法定条件(连续两次固限等),用人单位**单方终止 = 违法解除**。

## Z4 《浙仲〔2009〕2号》第38条:加班工资计算基数

- 权威层级: 地方规定
- 属地: zhejiang
- 来源: 课件1 P33
- 依据: 《关于劳动争议案件处理若干问题的指导意见(试行)》(浙仲〔2009〕2号)第38条
- verified: pending

### 计算基数确定顺序
1. **劳动合同约定的工资**为基数(约定优先);
2. 实行岗位技能工资制的单位,以**职工本人的岗位工资与技能工资之和**为基数;
3. 岗位/技能工资难以确定的,以**上月职工正常工作情况下的工资**为基数,同时**扣除绩效、奖金和物价补贴**;
4. 难以区分工资、奖金、物贴等项目的,以**职工上月实得工资的70%**为基数;
5. **兜底**:低于当地最低工资标准的,按当地最低工资标准为基数。

### 实务要点
- 🟧 浙江口径基数低于全国一般(全国默认合同约定的全部工资);
- ⚠️ "合同约定"应明确:避免把绩效/奖金/物贴等写进"工资"概念,以降低加班费基数。

## Z5 《浙江省企业工资支付管理办法》

### Z5.1 第十九条:5日内结清工资

- 权威层级: 地方政府规章
- 属地: zhejiang
- 来源: 课件1 P46
- 依据: 《浙江省企业工资支付管理办法》第十九条
- verified: pending

> 企业与劳动者**依法解除、终止劳动合同**的,应当**自办理解除或者终止劳动合同手续之日起5日内**一次性结清工资。

### 实务要点

### Z5.2 工资支付记录保存:2年
- 凭推断(课件提及"工资支付记录"在举证中的重要性),应在制度中明确**保存≥2年**;
- 浙江省实务:工资支付记录是核心举证责任对象,**未保留 = 推定欠薪**。

## Z8 浙江省劳动仲裁院《关于劳动争议案件处理若干问题的解答》

### Z8.1 十一:放弃社保承诺

- 权威层级: 地方裁判口径
- 属地: zhejiang
- 来源: 课件1 P38
- 依据: 浙江省劳动仲裁院《关于劳动争议案件处理若干问题的解答》第十一
- verified: pending

> 劳动者不愿意缴纳社会保险费,并书面承诺放弃参加社会保险的法律后果是什么?
> 劳动者不愿意缴纳社会保险费,并书面承诺放弃参加社会保险的,该书面承诺**无效**。劳动者可以用人单位未缴纳社会保险费为由解除劳动合同,但要求用人单位支付经济补偿的,**不予支持**。

### ⚠️ 与新法冲突
- 浙江省解答(2010年代口径):劳动者承诺放弃 → 无效,但劳动者**主张经济补偿 → 不支持**;
- 《劳动争议司法解释(二)》第十九条(2025.09施行):**新口径** → 未依法缴纳致劳动者按第三十八条第三项解除并要求经济补偿的,**人民法院依法予以支持**;
- ⚠️ **冲突**:新法施行后,该浙江省解答是否会被新解释覆盖,需**T3阶段以元典最新版本核验**。

### Z8.2 补充:工资支付记录保存
- 浙江省实务:工资支付记录保存≥2年(参见 Z5)。

### Z9.3 B航空案 P58-P61(争议解决全景应用)

- 权威层级: 司法判例
- 属地: zhejiang(主要为萧山区,本体系认定浙江口径)
- 来源: 课件4 P55-P61
- 依据: 课件引判决(未具名)
- verified: pending

#### 5项仲裁请求(P56)
1. 裁决被申请人向申请人支付拖欠的2024年3月至7月工资合计**59,701.28元**:
   - 3月份工资差额 12,205.91元
   - 4月份工资差额 13,053.49元
   - 5月份工资差额 14,523.02元
   - 6月份工资差额 14,585.49元
   - 7月份工资差额 5,333.35元
2. **违法解除赔偿金 483,335元** = 19,333.4元/月 × 12.5 × 2。

#### 4个争议焦点(P58-P61)
1. **管辖**:杭州有管辖权 — 实际工作地、社保缴纳地、合同履行地均在杭州萧山区(主要履行地);
2. **停飞期间工资**:公司**有权**进行不超过6个月的纪律停飞;不支付飞行补贴**不应视为欠付工资**;
3. **违法解除认定**:B航空以"严重违反规章制度"为由解除,**但理由不成立**:
   - 违规开房 ≠ 严重违纪;
   - 酒测视频**不构成同一视频**;
   - 调查过程中虽有陈述不一致,但**不构成严重不诚信**;
   - → **构成违法解除**;
4. **赔偿金基数**:按**停飞前12个月平均工资**(2023年3月至2024年2月) **19,333.4元/月** 计算,折合 **12.5个月** → 赔偿金 = **483,335元**。

#### 浙江实务推论
- **停飞期内工资**未必补发(司法尊重用人单位管理权);
- **赔偿金基数**按"正常工作状态"工资计算,避免用人单位拖延导致基数降低;
- **特殊群体保护规则**在航空场景的应用。

## 浙江口径速查卡

| 议题 | 浙江口径(与全国比较) |
|------|----------------------|
| 企业罚款权 | **无效**(全国多数省市一致) |
| 请假未批 = 旷工 | **不当然**(较全国更宽保护劳动者) |
| 终局裁决扩展 | **含社保补缴、工伤赔付**(浙江特殊) |
| 不定时工时年假3倍 | **不适用** |
| 加班工资基数 | 标准工资(可低于全国口径) |
| 离职5日结清工资 | **强制性**(浙江强条) |
| 工资支付记录保存 | **2年**(实务惯例) |
| 合同续订选择权 | **完全归属劳动者**(2025.12解答七) |
| 放弃社保承诺 | 旧口径不支持补偿 / **新法可能反向** |
| 停飞期内工资 | **不当然补发**(尊重管理权) |
| 违法解除赔偿金基数 | **正常工作状态工资**(避免停飞等异常期拉低) |
