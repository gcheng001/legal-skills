# 指控事实七要素提取表

针对起诉意见书/起诉书每一项指控事实，逐要素拆解。任一要素证据不足或存在合理怀疑，即构成辩点。本表配合"阅卷笔录标准结构"第二部分使用，不重复 12 部分骨架，只提供要素级的提取与陷阱识别方法。

---

## 一、七要素总表

| 要素 | 提取要点（看什么） | 常见陷阱 | 适用法条举例 |
|------|--------------------|----------|--------------|
| 时间 | 具体日期、时间段、持续时间；多次行为分别起止时间 | 笼统表述"2019年至2022年间"；跨时段行为凑成一笔；过追诉时效 | 《刑法》第89条追诉时效 |
| 地点 | 犯罪行为实施地、结果发生地、共犯分工地点 | 跨辖区拼凑管辖；以"等地"模糊关键地点；网络犯罪服务器地与行为地混用 | 《刑诉法》第25条地域管辖 |
| 人物 | 行为人、共犯分工、被害人、关系人；单位犯罪中的决策人 | 同名混同；共犯作用大小不分；被害人身份与定性错位 | 《刑法》第25-29条共同犯罪 |
| 手段 | 行为方式、工具、暴力程度、欺骗内容 | 把合法手段计入犯罪手段；手段描述与客观证据不符 | 罪状中的"手段"要件 |
| 金额/数量 | 涉案金额、违法所得、损失数额、物品数量、次数 | 重复计算；既遂未遂混算；币种汇率不统一；审计范围超出指控 | 罪状中的数额/情节要件 |
| 主观故意 | 故意、明知、目的；单位犯罪中单位意志 | 以客观推主观不论证；明知标准泛化；目的与动机混淆 | 《刑法》第14条故意犯罪 |
| 结果 | 危害后果、财物损失、人身伤害、社会影响 | 把关联结果当犯罪结果；损失评估方法存疑 | 罪状中的结果要件 |

## 二、各要素提取细则

### 2.1 时间要素

**提取要点**：
- 起诉书列明的每一笔犯罪，分别起止时间，精确到日
- 持续犯、连续犯：行为起止、间隔、频率
- 与立案时间、追诉时效起点对照

**常见陷阱**：
- [ ] 笼统时段表述掩盖单笔证据不足（"2019年至2022年间多次"）
- [ ] 跨年份行为凑成一连续行为
- [ ] 已过追诉时效的行为仍计入
- [ ] 节假日、休息日发生的"工作行为"合理性存疑

**示例**：起诉书称"2020年1月至2023年6月持续实施合同诈骗"，但合同主体公司2021年才注册——起点与主体资格矛盾，须剔除2020-2021段。

### 2.2 地点要素

**提取要点**：
- 行为实施地、结果发生地、合同履行地、资金流转地
- 网络案件：服务器地、终端地、IP归属地
- 与管辖文书对照

**常见陷阱**：
- [ ] 以结果地或抓捕地倒推管辖
- [ ] "等地"模糊关键地点掩盖管辖瑕疵
- [ ] 共犯异地分工未查清，作用认定偏差

### 2.3 人物要素

**提取要点**：
- 行为人基本信息、与同案关系、分工
- 被害人身份、与行为人关系
- 单位犯罪：决策主体、决策过程、利益归属

**常见陷阱**：
- [ ] 同名同姓人员混同（须身份证号或户籍核对）
- [ ] 共犯"主从犯"作用未区分，金额全算到主犯
- [ ] 单位犯罪中只抓自然人，遗漏单位意志论证
- [ ] 被害人实为民事相对方，定性错位

### 2.4 手段要素

**提取要点**：
- 罪状所列手段要件是否齐备（如诈骗罪的"虚构事实、隐瞒真相"）
- 客观证据印证的手段与供述手段是否一致
- 暴力程度、工具来源

**常见陷阱**：
- [ ] 把民事违约手段计入犯罪手段（如正常催收、商业折扣）
- [ ] 手段描述与书证、电子数据矛盾
- [ ] 共犯手段张冠李戴到所有人

### 2.5 金额/数量要素

**提取要点**：
- 涉案总额、单笔金额、违法所得、被害人损失
- 数量要素：毒品克数、物品件数、次数
- 计算依据：审计报告、司法鉴定、转账记录

**常见陷阱**：
- [ ] 重复计算：同一笔资金既算欺诈金额又算违法所得
- [ ] 既遂未遂混算（数额犯未遂应单独评价）
- [ ] 币种、汇率、计价时点不统一
- [ ] 审计范围超出指控事实，把无关业务计入
- [ ] 言词证据金额与客观转账金额不一致，未核对
- [ ] 抽成、返佣、提现等扣减项未查清

**示例**：指控诈骗金额500万，审计报告含300万正常业务流水——扣减后实际涉案200万，量刑档次可能从"数额特别巨大"降为"数额巨大"。

### 2.6 主观故意要素

**提取要点**：
- 直接故意/间接故意、明知程度、犯罪目的
- 客观行为推断主观故意的论证链
- 单位犯罪中单位意志的形成证据

**常见陷阱**：
- [ ] 以客观行为直接推主观，缺论证（如"收了钱未还"推非法占有，未排除经营失败）
- [ ] "明知"标准泛化，把"应当知道"等同于"明知"
- [ ] 目的与动机混淆（如炫富动机 ≠ 非法占有目的）
- [ ] 履约过程中的主观变化未分段评价
- [ ] 共犯之间主观故意内容不同，按同一故意认定

### 2.7 结果要素

**提取要点**：
- 危害结果是否发生、何时发生、与行为的因果关系
- 损失评估方法、评估机构资质
- 因果关系中断情形

**常见陷阱**：
- [ ] 把关联结果当犯罪结果（市场风险损失计入诈骗损失）
- [ ] 损失评估依据不充分（无原始凭证、仅凭报案人陈述）
- [ ] 因果关系中断未识别（被害人自陷风险、第三方行为介入）

## 三、要素提取操作清单

针对每笔指控事实，逐项核对：

- [ ] 时间：起止明确，未笼统，未过时效
- [ ] 地点：管辖成立，关键地点清晰
- [ ] 人物：身份无误，共犯作用区分，单位/自然人定性准确
- [ ] 手段：与罪状一致，与客观证据印证
- [ ] 金额/数量：来源清楚，未重复计算，未混算既遂未遂
- [ ] 主观故意：论证链完整，明知标准未泛化
- [ ] 结果：因果关系成立，评估依据充分

任一项存疑，在阅卷笔录第二部分对应指控项下标注"【要素存疑】+理由+卷宗页码"。

---

## 四、与辩护突破口的衔接

七要素中：
- 时间、地点、人物、手段、结果存疑 → 衔接 `defense-breakthrough-checklist.md` 的"核心事实推翻"
- 主观故意存疑 → 衔接"主观故意否定"
- 金额/数量存疑 → 衔接"金额数量降档"
- 取证过程对应要素存疑 → 衔接"非法证据排除""证据链断裂"

要素提取表不是终点，是辩护突破口的发现起点。每发现一处要素瑕疵，立即在阅卷笔录第十二部分"辩护思路"对应登记一条待查项。
