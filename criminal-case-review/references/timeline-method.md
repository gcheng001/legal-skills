# 多轨时间轴方法

把案件按四条平行轨道梳理时间线，标注矛盾、违规、有利三类节点。本方法不替代阅卷笔录的"证据分析"部分，只提供时间维度的梳理工具，便于在阅卷过程中识别时间冲突、程序违规、对被告有利节点。

---

## 一、四轨定义

| 轨道 | 内容 | 主要来源 |
|------|------|----------|
| A. 日期 | 公历日期、精确到日（必要时到时分） | 全卷所有材料 |
| B. 案件事实 | 指控事实、客观行为、资金流转、人员往来 | 起诉书、供述、书证、电子数据 |
| C. 取证活动 | 询问、讯问、搜查、扣押、勘验、鉴定、辨认 | 诉讼文书卷、证据卷首页 |
| D. 程序节点 | 立案、强制措施、移送、退补、起诉 | 诉讼文书卷 |

四轨同日横向对齐，便于发现"先取证后立案""超期羁押""单次讯问超24小时"等问题。

---

## 二、标注规则

| 标注 | 触发条件 | 处理 |
|------|----------|------|
| 【矛盾】 | 同一事实不同证据时间冲突；供述时间与客观证据时间冲突；资金流水时间与指控时间冲突 | 列冲突点、对应页码、可能影响 |
| 【违规】 | 取证时间早于立案；单次讯问超24小时；连续传唤间隔不足12小时；超期羁押；应当录音录像未录；首次讯问未告知权利 | 列违法情形、对应法条、是否可补正 |
| 【有利】 | 时间节点证明被告人不在场、无作案时间、行为在合法时段、已过追诉时效 | 列有利事实、对应证据、辩点方向 |

---

## 三、关键程序时限速查

依据《中华人民共和国刑事诉讼法》：

| 时限 | 法定要求 | 法条 |
|------|----------|------|
| 单次讯问 | 不得超过24小时 | 《刑诉法》第119条 |
| 连续传唤 | 间隔不少于12小时 | 《刑诉法》第119条 |
| 拘传 | 持续时间不得超过12小时；案情特别重大复杂需拘留逮捕的，不得超过24小时 | 《刑诉法》第119条 |
| 拘留后讯问 | 应当在24小时内讯问 | 《刑诉法》第86条 |
| 拘留期限 | 一般3日，可延长至7日，特殊可至30日 | 《刑诉法》第91条 |
| 逮捕后侦查羁押 | 一般2个月；复杂可延长1个月；四类案件可延长2个月 | 《刑诉法》第156-158条 |
| 退回补充侦查 | 每次1个月，以二次为限 | 《刑诉法》第175条 |
| 审查起诉期限 | 1个月，可延长15日；改变管辖重新计算 | 《刑诉法》第172条 |

## 三、常见时间冲突类型

| 冲突类型 | 典型表现 | 排查方法 |
|----------|----------|----------|
| 取证先于立案 | 立案决定书时间晚于首次询问、搜查、扣押时间 | 比对受案登记、立案决定书与各询问/搜查笔录首页时间 |
| 讯问超时 | 单次讯问起止时间跨度过长 | 比对每次讯问笔录首页起止时分，扣除合理休息 |
| 连续传唤间隔不足 | 上次传唤结束与下次开始间隔不足12小时 | 列出连续传唤节点，计算间隔 |
| 强制措施超期 | 拘留、逮捕后羁押超过法定期限 | 比对强制措施文书与起诉、变更时间 |
| 资金时间与指控不符 | 指控挪用时间早于资金到账时间 | 比对银行流水、转账记录与起诉书指控时间 |
| 不在场时间 | 指控作案时间被告人有正当活动 | 比对通讯记录、监控、考勤、票据 |
| 追诉时效 | 行为发生至立案超过追诉时效期限 | 按法定最高刑计算时效（《刑法》第87条） |

排查方法通用步骤：先列时间，再算间隔，再核对法定要求，最后标注类型与卷宗页码。

## 五、冲突处理优先级

同一节点出现多类标注时，按以下优先级处理：

1. **【违规】优先**：程序违法可能引发非法证据排除，影响定性
2. **【矛盾】次之**：证据间矛盾可能动摇事实认定
3. **【有利】并行**：有利事实独立登记，不因前两者存在而忽略

例：2021-10-17 讯问同时存在【违规】（超时）与【有利】（甲首次供述但系诱导），先处理违规（申请排除），再登记有利（翻供理由）。

## 六、时间轴制作操作清单

- [ ] 摘录起诉书每一笔事实，按时间排序入B轨
- [ ] 摘录所有讯问、询问时间入C轨
- [ ] 摘录立案、强制措施、移送、退补入D轨
- [ ] A轨日期统一为YYYY-MM-DD格式
- [ ] 横向对齐：同一日期四轨并列
- [ ] 逐节点核对：是否【矛盾】/【违规】/【有利】
- [ ] 每个标注后跟：卷宗页码 + 法条依据（违规时） + 辩点方向
- [ ] 时间轴单独成表，不混入阅卷笔录正文，但可在第十部分"证据分析"中引用结论

## 七、与其他 reference 的衔接

- 时间轴发现【违规】→ 衔接 `defense-breakthrough-checklist.md` 的"非法证据排除"
- 时间轴发现【矛盾】→ 衔接 `fact-elements-checklist.md` 对应要素存疑
- 时间轴发现【有利】→ 衔接 `defense-breakthrough-checklist.md` 的"核心事实推翻"
- 时间轴上单次讯问超时、连续传唤间隔不足 → 衔接 `evidence-examination-checklist.md` 的"被告人供述"质证维度

时间轴是阅卷过程中的横向比对工具，不是阅卷笔录的必备章节，但其发现必须回写至阅卷笔录对应部分（第十部分证据分析、第十二部分辩护思路）。
