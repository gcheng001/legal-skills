# 阅卷笔录提交版/自用版双版本规范

> 2026-09-30 起强制执行。起因：阅卷笔录中"需核对原件""辨识存疑照卷面抄录"等表述随归档卷提交法律援助中心后，会被认定"未完成核对"并要求律师到场补正，直接影响法援案件评价与承办律师信誉。

## 一、双版本机制（默认输出）

1. 每案阅卷默认产出两版：
   - **提交版**（`XX案_阅卷笔录.docx/.pdf`，存 `02_正式文书/`）：可直接交法援中心归档的最终版，不含任何未完成核查的自认表述。
   - **自用版**（`XX案_阅卷笔录_自用版.docx`，存 `02_工作底稿/`）：保留待核实要点、矛盾点清单、会见准备问题等工作内容，供承办律师办案使用。
2. 用户明确只要提交版的：剥离要点全部转入案件 `CLAUDE.md` 底稿（"提交版剥离要点（自用备查）"节），不留第二版本。
3. 需要归档合并卷（如"归档-姓名.pdf"：封面目录＋通知书＋起诉意见书＋阅卷笔录＋会见笔录＋法律意见书＋具结书＋工作记录表）时，装入的一律是提交版。

## 二、提交版硬性禁词（出现即返工）

### 1. 未完成核查认账类

需核对 / 待核对 / 应核对 / 须核对 / 核对原件 / 需与纸质卷核对 / 待与纸质卷核对 / 经抽样辨识 / 抽样识别 / 辨识存疑 / 存疑照抄 / 不可读 / 正文不可辨 / 无法辨识 / 未能查看 / 电子阅卷未能 / 待会见核实 / 会见时必须核实 / 向检察机关核实 / 应向检察机关核实 / 向办案机关核实 / 向办案机关调取 / 需另行调取核对 / 待落实 / 待补充清单 / 待核（标题及"待核实事项""待核实问题"类小标题） / 文号待核验 / 具结前应 / 庭前应完成 / 空白点 / 待终核 / 需会见补充

### 2. 工作流程痕迹类（AI 味）

渲染 / 工作底稿 / 汇总稿 / 无文字层 / 文本层 / OCR / 分页 / 以超大文件方式 / 逐页视觉识别 / null（自己流程产生的，原卷真实印错的除外）

### 3. 文件名式引用类

- 卷名不带文件日期后缀：补充侦查工作卷20260731 → **补查卷一**、补充侦查工作卷20260902 → **补查卷二**、工作卷20260818 → **工作卷**（多本补查卷按时间先后编一/二）。
- 不引用 PDF / txt / docx 等电子文件名，不写"电子文本""文本提取"等过程性说法。

## 三、改写方向（四式）

| 情形 | 改法 | 示例 |
|------|------|------|
| 扫描件看不清、无法辨认 | 中性事实陈述 | "均为扫描图像""系扫描图像，次数不详" |
| 内容已经其他在卷材料印证 | 完成式 | "相关内容已结合归案经过等在卷记载予以核对""以7月27日笔录为据""经与XX核对后更正" |
| 属后续辩护动作 | 辩护请求式 | "辩护中将申请调取该三段视频""建议侦查机关出具补正或说明材料""将申请侦查人员出庭说明或调取出入库登记予以澄清" |
| 卷面与目录不一致、缺件 | 中性对照/事实陈述 | "目录登记与原件落款不一致""以卷面记载为准""卷内未附（在另案卷）" |

其他改写要点：
- "本卷未附／本卷未见" → "卷内未附／卷内未见"。
- "待终核" → "待最后核对"；能删则删（如"经审查，未发现程序违法情形"）。
- 搭配不当一并修："建议贵院予以坚持" → "建议贵院采纳并依法作出不起诉决定"（针对相对不起诉量刑建议）。
- 事实定性不得拔高：与被害人仅系相识的，"亲友间债务纠纷"应为"债务纠纷"。
- 文号/法条：经权威来源（如北大法宝）核验后才写具体文号；核不准就只写文件名称＋发布机关＋发布日期，不写"待核验"。已核实备案：浙高法〔2013〕257号＝浙江诈骗罪数额标准（6000元/10万/50万三档）。

## 四、保留例外（不得误删）

以下内容是阅卷质量和辩护价值的体现，**不属于**违规表述：

1. 攻击侦查机关的实质瑕疵分析：如"受案登记表形成时间存疑""现场提取刀具与扣押刀具是否同一存疑""存疑指认""填载异常"。
2. 证人／嫌疑人原话引用（如证言"当天在现场没有看到王建鹤"）。
3. 原卷文书真实印刷错误的如实记载（如受案登记表文号印"null"、检测仪 WAT 型号、微信号 wjhzyy0808 等真实编号）。
4. 法定表述（"起次要或者辅助作用"等刑法条文用语）。
5. 法条／司法解释原文引用及配套管辖条款。

## 五、剥离要点去向（不得凭空消失）

提交版删除的待核实要点、矛盾点、会见准备问题，必须完整落入：
- 自用版对应部分；或
- 用户只要提交版时 → 案件 `CLAUDE.md` 追加"提交版剥离要点（自用备查）"节。

## 六、交付前自检（强制）

1. **全文复扫禁词**：按第二节字样逐一定位，残留清零。
2. **编号衔接检查**：整段删除后小标题不得跳号、重号（删"3、"后原"4、"应顺延或保持序列连续；特别警惕清单收尾段漏删）。
3. **修改页视觉验收**：改动集中页渲染后核对版面、断句、字体。
4. 自用版与提交版内容差异仅限本规范允许范围，事实性内容两版一致。
