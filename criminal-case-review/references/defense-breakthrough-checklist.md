# 辩护突破口6类识别表

阅卷过程中实时识别辩点。本表不替代阅卷笔录第十二部分"辩护思路"，只提供辩点类型的识别标准与示例，便于在阅卷时即时标注、收尾时汇总。

---

## 一、6类突破口总表

| 类型 | 识别标准 | 典型示例 | 辩点方向 |
|------|----------|----------|----------|
| 1. 非法证据排除 | 取证程序严重违法，可能严重影响司法公正 | 无证搜查、刑讯逼供、应当录音录像未录 | 申请排除，削弱控方证据体系 |
| 2. 核心事实推翻 | 控方认定的关键事实缺乏证据支撑或存在反证 | 资金去向显示用于经营而非个人消费 | 无罪或罪名变更 |
| 3. 主观故意否定 | 被告人不具备犯罪故意或目的 | 有前期履约行为，亏损系经营风险 | 无罪或罪轻 |
| 4. 法定从宽情节 | 法律明文规定的从轻、减轻、免除情节 | 自首、立功、从犯、未遂、中止 | 量刑减让 |
| 5. 金额数量降档 | 涉案金额或数量降至更低量刑档次 | 审计金额低于指控金额，跨档 | 量刑档次下调 |
| 6. 证据链断裂 | 关键证据缺失或无法形成完整链条 | 仅被害人陈述，无其他证据印证 | 孤证不能定案 |

---

## 二、逐类识别细则

### 2.1 非法证据排除

**识别标准**：
- 取证主体、程序、形式违反法定要求
- 违法程度达到"可能严重影响司法公正"
- 不能补正或作出合理解释

**典型示例**：
- 无搜查证搜查（例外情形除外）
- 刑讯逼供、暴力、威胁取得供述
- 应当同步录音录像的案件未录像（《公安机关办理刑事案件程序规定》第208条规定的重大犯罪案件）
- 单次讯问超24小时、连续传唤间隔不足12小时
- 扣押清单无见证人签名
- 辨认前让辨认人见到被辨认对象

**对应辩点方向**：
- 申请非法证据排除（《刑诉法》第56-60条）
- 提供线索：入所体检表、同监室证言、伤痕照片、提讯登记
- 申请调取同步录音录像、讯问笔录、看守所健康检查记录
- 不能排除的，相关证据不得作为定案根据

### 2.2 核心事实推翻

**识别标准**：
- 指控事实的某一构成要件缺乏证据支撑
- 客观证据与指控事实相反
- 关键事实仅有孤证

**典型示例**：
- 合同诈骗案：审计显示资金用于进货、发工资，非个人消费
- 盗窃案：被指控作案时间被告人有不在场证据
- 受贿案：行贿人陈述的资金来源不清、行贿时间地点矛盾
- 故意伤害案：被害人事后承认系自己摔倒

**对应辩点方向**：
- 该要件事实不清、证据不足
- 主张相反事实并提供反证
- 主张罪名不成立或变更为较轻罪名

### 2.3 主观故意否定

**识别标准**：
- 被告人不具备犯罪故意（直接/间接）
- 不具备特定目的（如非法占有目的、牟利目的）
- 客观行为与主观故意的论证链断裂

**典型示例**：
- 合同诈骗案：有真实履约行为、积极补救损失、对外负有正常经营债务
- 帮信案：出租银行卡时不知道对方用于犯罪，已尽合理审查
- 掩隐案：交易价格、方式符合市场惯例，无反常迹象
- 共犯：仅提供劳务，不明知主犯犯罪

**对应辩点方向**：
- 主观故意证据不足，不能认定
- 客观行为不能直接推定主观故意，需排除合理怀疑
- 区分民事欺诈与刑事诈骗

### 2.4 法定从宽情节

**识别标准**：
- 自首：自动投案，如实供述（《刑法》第67条）
- 立功：揭发他人犯罪、提供侦破线索（《刑法》第68条）
- 从犯：在共同犯罪中起次要或辅助作用（《刑法》第27条）
- 未遂：已经着手，因意志以外原因未得逞（《刑法》第23条）
- 中止：自动放弃犯罪或自动有效防止结果发生（《刑法》第24条）
- 未成年、孕妇、七十五周岁以上（《刑法》第17条之一、第49条）

**典型示例**：
- 电话通知到案并如实供述，可认定自首
- 到案后揭发同案犯以外的其他犯罪，查证属实
- 共同诈骗中仅负责接送、记录，未参与分赃或分赃极少
- 盗窃既遂前被当场抓获，财物未失控

**对应辩点方向**：
- 提出法定从轻、减轻、免除处罚情节
- 主张基准刑下浮（参照量刑指导意见）
- 数额犯跨档时，减轻处罚可下调量刑档次

### 2.5 金额数量降档

**识别标准**：
- 审计/鉴定金额低于指控金额
- 重复计算、混算、关联业务计入
- 既遂未遂混算、扣减项未查清
- 毒品数量含水分（掺杂掺假）、非毒品杂质

**典型示例**：
- 诈骗案：指控500万，审计含300万正常业务，实际涉案200万，从"数额特别巨大"降为"数额巨大"
- 盗窃案：指控10万元，含已退回的1万元，实际9万元
- 毒品案：海洛因含量鉴定显示纯度低，应按实际含量折算

**对应辩点方向**：
- 重新计算涉案金额
- 申请重新鉴定或补充审计
- 主张按较低量刑档次处罚

### 2.6 证据链断裂

**识别标准**：
- 关键环节无证据支撑
- 证据间无法相互印证
- 存在孤证定案情形
- 合理怀疑无法排除

**典型示例**：
- 受贿案：仅有行贿人陈述，无资金流转证据
- 盗窃案：现场未提取到被告人指纹、DNA，无赃物
- 诈骗案：被害人与被告人陈述一对一，无书证、电子数据印证
- 故意杀人案：凶器未找到，被告人翻供

**对应辩点方向**：
- 证据达不到"确实、充分"证明标准
- 不能排除合理怀疑（《刑诉法》第55条）
- 主张无罪或存疑不起诉

## 三、突破口发现操作清单

阅卷过程中，针对每项指控事实和每份证据，逐项核对：

- [ ] 取证程序是否合法？是否达到"可能严重影响司法公正"？→ 类型1
- [ ] 指控事实是否每一构成要件均有证据支撑？是否有反证？→ 类型2
- [ ] 主观故意论证链是否完整？是否有相反证据？→ 类型3
- [ ] 是否存在自首、立功、从犯、未遂、中止等情节？→ 类型4
- [ ] 金额/数量是否准确？是否有重复计算、混算？→ 类型5
- [ ] 关键证据是否齐备？证据间能否相互印证？→ 类型6

## 四、突破口汇总格式

阅卷收尾时，将发现的突破口按以下格式汇总至阅卷笔录第十二部分：

```
辩护思路（基于阅卷发现）

1. 非法证据排除类
   - 2021-10-17讯问单次超24小时（卷3第45页），申请排除该次供述
   - ...

2. 核心事实推翻类
   - 指控挪作他用的300万，转账凭证显示系购货款（卷2第78页）
   - ...

3. 主观故意否定类
   - ...

4. 法定从宽情节类
   - 电话通知到案并如实供述（卷1第12页），构成自首
   - ...

5. 金额数量降档类
   - 审计金额含300万正常业务（卷4审计报告），扣减后实际涉案200万
   - ...

6. 证据链断裂类
   - ...
```

每条辩点须标注：事实依据 + 卷宗页码 + 法律依据 + 预期效果。无页码、无法律依据的辩点不得写入。

## 五、与其他 reference 的衔接

- 类型1（非法证据排除）→ 配合 `evidence-examination-checklist.md` 各类证据的合法性维度
- 类型2（核心事实推翻）、类型5（金额数量降档）→ 配合 `fact-elements-checklist.md` 要素提取
- 类型6（证据链断裂）→ 配合 `evidence-examination-checklist.md` 证据链整体评估
- 时间维度发现 → 配合 `timeline-method.md` 标注节点

六类突破口不是孤立的，常常交叉出现。一份非法讯问同时构成类型1（非法证据排除）与类型6（排除后证据链断裂）；一笔错误金额同时构成类型2（核心事实推翻）与类型5（金额降档）。汇总时应交叉引用，避免重复论证。
