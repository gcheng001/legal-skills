# ADR-0003：九步法融合（case-os × mqc）—— 主链中性 + 末端立场出口 + 核验纪律强化

- **状态**：Accepted（部分落地）
- **日期**：2026-07-08
- **决策者**：高澄
- **关联**：详细 17 条 ADR 与术语表见 `~/Codepilot/skill-merge-nine-step/融合-ADR与术语表.md`；本案实证见 `~/Codepilot/skill-merge-nine-step/肖永吉-三版对比/`；核验纪律已落 `case-s10-hallucination`

## 背景

引入 mqc-claim-basis-nine-step v1.1.0（律师立场九步法）后，与 case-os v11.1（法官中性九步法）形成两套并行。两套同源（邹碧华九步法 + 请求权基础方法 + Rosenberg 规范说），但各有独家：

- **case-os 独家**：S10 门禁、证据三件套（可采性/关联性/证明力）、全周期、法官中性
- **mqc 独家**：立场打法层（N6-N9）、区间预测、三图、客户摘要五维、§0 核验纪律

**肖永吉-追偿权纠纷案三版对比实证**（2026-07-08）：
1. 两套中性归入结论一致（追偿权驳回 60-85%，融合不破坏中性）
2. case-os 自动产物（v10.0 深度报告）有 **6 个占位类案**（12345/67890 连号）+ **漏引侵权解释(一)第15条** → 核验纪律缺失的铁证
3. mqc 无证据三件套、无 S10 兜底
4. 主人手工写的庭审材料类案全部真实 —— 印证核验纪律应主要针对自动产物

## 决策

融合方案三层结构，**主链零侵入**：

### 1. 字段层（ADR-001~009，主链各步加字段，向后兼容）
- `case_basic_info` 扩展：时态（前瞻/回溯）、材料成熟度、代理立场（从当事人推出）
- S2 加复验状态 + 定性风险 + 请求权竞合初选
- S3 抗辩：被动提取 → 全谱系穷举 + 抗辩/抗辩权二分（须主张标记）+ 分级显示
- S4 要件 + 争点双层（要件作底，related_element 非空）+ 定性风险
- S6 加对手主攻线预判
- S7 加初步前景 + 证明标准细化（本证/反证/排除合理怀疑）
- S8 证据三件套保留 + 前景四档 + 争议状态 + 修正因素 + 决定性标记
- S9 单点 → 区间（上限/中位/下限）+ 最坏情形 + 对手行为预判 + 类案校准

### 2. 门禁/流程层（ADR-010~012）
- **核验纪律强化**（✅ 已落 `case-s10-hallucination`，本 ADR 第一落地项）：
  - 类案真实性校验（案号反查元典库 + 连号指纹检测）→ schema 语义约束8/9 CRITICAL 阻断
  - 法条 + 关联解释全谱检索（不只查主条，防漏引第15条类错误）
- N0 程序站（A4 后/S1 前，驳回起诉风险预判：管辖/主体/重复起诉）
- N5 行动清单（S8/S9 缺口 → 取证/鉴定/书证提出命令，五字段结构）

### 3. 末端出口层（ADR-013~017，挂 S10 通过后）
立场打法 N6-N9，**主链保法官中性，立场只在末端出口出现**：
- 攻防着力点（决定性要件 × 立场的投影）
- 诉请策略优化（备位/金额拆解/组合，举证届满前输出）
- 时效失权守则（被告向安全条，强制提醒）
- 成本收益（锚《诉讼费用交纳办法》+ 偿付能力）
- 客户摘要五维（可能性/成本/时效/周期/风险，红圈所纪律，律师版/客户版不混发）

**根判断（ADR-001）**：分析立场（对抗倾向）不进主链，仅末端出口使用。case-os 主链结构零侵入。

## 备选方案与取舍

- **两套并行不融合**：放弃。一个流程拿不到中性归入 + 立场出口 + 核验，切两套费时
- **mqc 替换 case-os**：放弃。S10 门禁、证据三件套、全周期是 case-os 根价值，mqc 没有
- **融合（本方案）**：主链中性骨架不动，mqc 长在字段层和末端出口。代价：字段扩展需向后兼容、末端出口层需新建

## 后果

- **正向**：一个流程拿到中性归入 + 立场出口 + 核验；本案实证融合版两全，且发现了 case-os 单跑时漏掉的抗辩漏洞（第15条）
- **负向**：字段层 + 末端出口层需逐步实施；schema 扩展要保证向后兼容（新字段 optional）
- **遗留**：立场打法层（N6-N9）需新建子 skill 或挂 case-os 末端，工作量较大
