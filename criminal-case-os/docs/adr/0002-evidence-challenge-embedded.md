# 质证意见嵌入阅卷笔录，不独立成文书 skill

## 背景

质证意见可以独立成一个 skill（如外部 defense-workflow 包的设计：阅卷分析报告 / 质证意见 / 辩护词三件套并行），也可以嵌入阅卷笔录。2026-07-04 反哺 defense-workflow 时再次浮现这个架构选择。

## 决策

质证**嵌入阅卷笔录**，不独立成质证文书 skill：
- A类阅卷笔录：质证落在第10部分"证据分析"（合法性/关联性/证明力/矛盾点）。
- B类证据分析报告式：质证落在第3部分"逐证三性分析表"（含 ✅/⚠️/❌ 量化评分）。
- 9类证据逐一质证要点作为 reference 供阅卷时调用（`evidence-examination-checklist.md`）。

## 理由

阅卷与质证在律师实务是连续动作——边阅边质，证据问题在阅卷过程中即时浮现。拆成两个独立 skill 会割裂流程、增加交接损耗（两次读取同一批证据、重复建立证据编号）。

B类报告式结构已把质证做成可独立查阅的章节（逐证三性表），满足了"质证成果独立可读"的需求，无需再拆 skill。

## 与庭审质证的区分

阅卷阶段的质证是**书面分析**（嵌阅卷笔录）；庭审阶段的质证是**庭上发问与举证质证提纲**（口语化、对抗性），由 `criminal-trial-examination` skill 承担。两者产物形态不同，分属阅卷与一审阶段。

## 复议条件

若未来出现以下情况，可重新评估是否独立：
- 庭前会议需要单独提交书面《质证意见书》成为高频需求；
- 阅卷与质证的工作主体分化（不同人负责）。
