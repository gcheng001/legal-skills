# 二审阶段排除在刑事OS范围外

## 背景

刑事OS覆盖侦查（拘留→批捕）、审查起诉、一审三个阶段，明确**不纳入二审**。system-overview 顶部把"二审已排除"作为体系边界声明。

## 决策

刑事OS一期范围 = 侦查 + 审查起诉 + 一审。二审、再审/申诉不在内。

## 理由

二审的核心工作是对一审判决的错误论证（事实认定错误、法律适用错误、程序违法、量刑不当），工作产物（刑事上诉状、二审辩护词）的论证结构与一审辩护差异显著。把二审一并纳入会摊薄一期在每个阶段的深度。

二审留待未来按需扩展。当前若遇二审需求，律师可基于一审产物（阅卷笔录、辩护词）手工衔接，或单独触发相关文书 skill。

## 边界

- 一审辩护词（`criminal-defense-statement`）的产出可被二审复用，但本系统不为二审生成专门文书。
- 再审/申诉同理排除。
