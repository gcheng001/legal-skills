# ADR 0005:量刑辩护与认罪认罚协商按"受众"划界

> 状态:已通过(v3.3,2026-07-22)
> 决策背景:融合 criminal-defense-workflow v3.1.0 引入量刑辩护专项时,需要厘清其与已有 `criminal-plea-bargain` 的边界,避免两套机制并行导致的工作冗余或逻辑冲突。

## 一、背景

刑事案件涉及"量刑"的工作分布在两个阶段、面向两个对象:

1. **审查起诉阶段(具结前)**:与检察官就量刑建议进行协商,争取更轻的量刑建议写入具结书
2. **一审阶段(具结后或不具结)**:向法院呈交量刑辩护意见,争取法院在量刑建议基础上进一步从宽

criminal-case-os 已有 `criminal-plea-bargain`(认罪认罚协商策略意见书生成)承载第 1 项;criminal-defense-workflow v3.1.0 提供的 `sub-skills/10_量刑辩护专项` 可承载第 2 项。两套机制必须明确划界,避免:
- 同一案件在同一阶段被两套机制并行处理
- 律师误触发导致重复工作或文书口径冲突
- 量刑数字在不同阶段被不同 skill 独立测算且互不核对

## 二、决策

**按"受众+阶段"双重维度划界:**

| 维度 | `criminal-plea-bargain`(已有) | `criminal-sentencing-defense`(v3.3 新建) |
|------|--------------------------|--------------------------------|
| **受众** | 检察院 | 法院 |
| **阶段** | 审查起诉(具结前) | 一审(具结后或定罪后) |
| **产物** | 认罪认罚协商策略意见书 + 大白话决策建议书 | 量刑计算表(工作底稿) + 量刑辩护意见(正式文书,可独立提交) |
| **工作重点** | 与检方的协商边界、筹码交换、底线条款 | 情节清单、档位判断、缓刑论证、罚金测算、类案同判 |
| **受众法律后果** | 检方是否出具更宽量刑建议 | 法院是否在建议刑期以下/以上宣告 |

## 三、理由

1. **受众不同**:向检察官呈现的工作是"协商",目的是取得检方的让步;向法院呈现的工作是"说服",目的是取得法院的采纳。两者的说服逻辑与文本风格截然不同。
2. **阶段不同**:审查起诉阶段尚未起诉,工作成果以具结书/量刑建议书形式存在;一审阶段已起诉,工作成果以法庭辩论+量刑意见书形式存在。
3. **避免数字口径冲突**:同一案件的量刑数字,若由两套机制独立测算,可能在不同产物中给出不一致的区间,引发律师与当事人疑虑。
4. **符合律师工作直觉**:实务中律师明确区分"与检察官谈"与"向法院说"——按受众划界符合工作流。
