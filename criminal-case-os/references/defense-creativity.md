# 辩点创意六路径（defense-creativity）

> 来源：跨界改写自 `laoshimu-creativity`（创造力六路径起跑线协议，composes-with）。本文件不复制其正文，仅将其思维算子迁移到刑事辩护语境。
> 定位：`criminal-defense-strategy` 工具 1.5（辩点发散）的方法论底稿。
> 🔴 检查点：**发散产物一律不直接进入文书**——须经《辩护策略分析与路径选择报告》"待核实线索"附表与 handoff 辩点处置清单（disposition_list），由律师确认后方可进入任何下游文书。🛑
> 红线对齐：去AI味、确认机制、系统独立立场（不迎合）全部适用于本模块。

## 路径一：种子记录法（难受点攒规律）

- **原路径**：记"这也太烂了"，攒 10 条找规律。
- **辩护改写**：每次归档复盘，在《刑事归档清单》"难受点种子"栏记 **3 条**——本案哪个瞬间最险/最憋屈/差点翻车（如"质证时才发现笔录矛盾""量刑建议出来才知道有前科情节"）。攒满 10 条做一次回顾：反复出现的是哪类盲区？把规律写成一条检查项，回流 `case-experience-card` 与本 OS 的 references。
- **判停**：规律没有复现 3 次以上，不成检查项。

## 路径二：三约束收窄（单点突破）

- **原路径**：1 工具 + 1 下午 + 1 问题。
- **辩护改写**：辩点久攻不下时，收缩为 **1 份卷宗材料 + 1 个程序节点 + 1 个辩点方向**（如"只看第 3 次讯问笔录 + 只看取证程序 + 只攻供述合法性"）。约束越紧，突破口越快出现。
- **判停**：一个约束组合推演 30 分钟无产出，换组合，不死磕。

## 路径三：烂原型（手比脑子快）

- **原路径**：先做粗糙原型再迭代。
- **辩护改写**：**三行话辩点草案**——每个候选辩点只写三行：①事实锚点（卷几页几/证据编号）②法律依据（法条/司法解释/指导案例，须元典 MCP 核验）③攻击对象（起诉书第几点/笔录第几份/鉴定意见第几项）。三行写不出来的辩点，说明还没想清楚，放回"待核实线索"。
- **判停**：草案阶段禁止润色措辞、禁止展开论证——那是下游文书 skill 的事。
- **fallback**：元典 MCP 不可用 → 该辩点标注[未经核验]留"待核实线索"附表，禁止凭记忆引用法条/案例编号。

## 路径四：跨界偷（类比论证库）

- **原路径**：跨领域收集 dots → 拆解三问 → 迁移。
- **辩护改写**：从其他部门法与治理领域偷裁判逻辑做攻防类比——行政法（比例原则攻刑罚必要性）、劳动法（举证责任分配）、金融监管（合规出罪逻辑）、平台治理（技术中性抗辩）。拆解三问：①该领域规则解决什么结构性问题？②本案是否存在同构问题？③迁移后论证强度够不够独立成辩点？
- **判停**：类比必须落在真实规范或真实案例上（元典 MCP 核验），找不到落点的类比只留在内部讨论，不入 disposition_list。
- **fallback**：元典 MCP 不可用 → 类比辩点整体标注[未经核验]留"待核实线索"附表，禁止凭记忆引用案例编号。

## 路径五：空白 30 分钟（静默复盘）

- **原路径**：放空让默认模式网络连接想法。
- **辩护改写**：辩点矩阵成型后、强度评估前，**不查法条、不写文书**，把案情时间线从头走读一遍（案内现在时锚定），只记录直觉疑点——哪里时间对不上、哪句话不像当事人会说的话、哪份证据出现得太顺。直觉疑点全部转"待核实线索"附表。
- **判停**：仅限一次/案件，不替代证据审查。

## 路径六：只为自己爽（内在动机对齐）

- **原路径**：做让自己爽的事，靠内在动机续航。
- **辩护改写**：对齐 OS 灵魂原则——**辩护贯穿全程，当事人利益是唯一准星**。发散阶段不为"辩点数量好看"凑数，不为炫技加类比；一个辩点若对当事人利益无增量（不改变定性、不降低刑期、不影响证据能力），不入清单。
- **判停**：与"系统独立立场"同向——发现某辩点有反噬风险（如暴露更不利事实），当场写明并劝阻。

## 反例黑名单（不要做）

- **凑数**：为"辩点数量好看"添加对当事人利益无增量的辩点。
- **炫技类比**：无真实规范/案例落点的跨界类比（元典 MCP 核验不过即弃）。
- **草案期润色**：烂原型阶段展开论证或打磨措辞。
- **反噬不报**：发现辩点可能暴露更不利事实而隐匿不劝阻。
- **越权入文书**：发散产物绕过 disposition_list 直接进入任何文书。

## 使用顺序建议

常规案件：工具 1（矩阵）→ 工具 2（强度评估）即可；**下列情形启用发散**：①辩点矩阵 ≤3 条且定罪风险评估偏高；②律师对现有辩点不满意；③疑难新型案件（要件库与罪名专项 skill 覆盖不足）。发散顺序：五（静默复盘）→ 一（种子回顾）→ 三（烂原型）→ 四（跨界偷）；二、六为全程纪律。
