# 刑事归档清单

> **用途**:刑事案件办结后的卷宗归档材料清单与装订顺序参考。
> **触发场景**:criminal-case-os 案件结案后由 case-archive skill 调用本清单完成归档;归档同时触发 case-experience-card 沉淀经验。

---

## 一、归档材料清单

### 1.1 委托手续
- [ ] 委托合同
- [ ] 授权委托书
- [ ] 律师事务所函
- [ ] 当事人身份证明复印件

### 1.2 工作文书
- [ ] 会见笔录
- [ ] 阅卷报告
- [ ] 质证意见
- [ ] 辩护词
- [ ] 庭审发问提纲
- [ ] 庭审辩论提纲
- [ ] 各类申请书(取保、回避、证人出庭、非法证据排除等)
- [ ] 量刑辩护意见(由 criminal-sentencing-defense 输出)

### 1.3 司法机关文书
- [ ] 起诉书 / 起诉意见书
- [ ] 判决书 / 裁定书
- [ ] 上诉状(如有)
- [ ] 二审裁判文书(如有)
- [ ] 量刑建议书

### 1.4 证据材料
- [ ] 证据清单
- [ ] 关键证据复印件
- [ ] 新证据(如有)
- [ ] 鉴定意见 / 审计报告

### 1.5 其他材料
- [ ] 案件状态头(CLAUDE.md 副本)
- [ ] 工作日志
- [ ] 通信记录
- [ ] 费用清单
- [ ] 经验沉淀卡(case-experience-card)

---

## 二、归档顺序(装订)

1. 卷宗封面
2. 卷内目录
3. 委托手续
4. 工作文书(按时间顺序)
5. 司法机关文书
6. 证据材料
7. 其他材料
8. 备考表

---

## 三、卷宗封面模板

```
┌─────────────────────────────┐
│                             │
│      XXX律师事务所          │
│                             │
│      刑事辩护卷宗           │
│                             │
│  案由:XXX                   │
│  被告人:XXX                 │
│  承办律师:XXX(从状态头读取) │
│  收案日期:YYYY年MM月DD日    │
│  结案日期:YYYY年MM月DD日    │
│  结案方式:判决/撤案/不起诉  │
│                             │
│  卷数:第X卷 共X卷           │
│                             │
└─────────────────────────────┘
```

> 封面所有当事人姓名、承办律师、律所名称必须从案件状态头(CLAUDE.md)读取,禁止硬编码。
