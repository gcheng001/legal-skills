# 非法证据排除速查

> **用途**:为刑事辩护律师提供按证据类型分类的非法证据排除(排非)规则速查,辅助快速判断证据可采性与排除路径。
> **适用范围**:供 criminal-case-os 全系统子 skill 调用。
> **定位红线**:本速查仅作导航;具体案件排除请求应结合排非申请模板使用,且程序性辩护与 criminal-defense-strategy 协同。

---

## 一、按证据类型分类的排非规则速查表

| 证据类型 | 绝对排除情形 | 裁量排除情形 |
|---------|------------|------------|
| 被告人供述 | 刑讯逼供、暴力/威胁取得;采用刑讯逼供等非法方法收集 | 未按规定录音录像;讯问笔录与录音录像不一致 |
| 证人证言 | 暴力/威胁/引诱取得;未个别询问 | 询问地点、程序不规范 |
| 被害人陈述 | 暴力/威胁/引诱取得 | 程序不规范 |
| 物证/书证 | — | 收集程序违法,可能严重影响司法公正且不能补正 |
| 电子数据 | 无法保证原始性 | 收集程序有瑕疵 |
| 鉴定意见 | 鉴定机构/人员不具备资质 | 鉴定程序不符合规定 |

**说明**:
- **绝对排除**:一经查实,该证据应当依法予以排除,不得作为定案根据,且不可补正或合理解释。
- **裁量排除**:属程序瑕疵,能补正或作出合理解释的可采用;不能补正或合理解释的,予以排除。
- **重复供述**:采用刑讯逼供等非法方法使被告人作出供述后,又作出的重复性供述原则上一并排除(除非依法定情形阻断,如侦查阶段更换侦查人员并告知诉讼权利及认罪法律后果后重新供述)。

## 二、非法取证情形识别

### 2.1 刑讯逼供

| 情形 | 识别标准 | 线索来源 |
|:---|:---|:---|
| **肉刑** | 殴打、捆绑、违法使用戒具等 | 入所体检表、伤痕照片 |
| **变相肉刑** | 冻、饿、晒、烤、疲劳审讯 | 讯问笔录时间、提讯记录 |
| **精神折磨** | 威胁、恐吓、欺骗、引诱 | 同步录音录像、被告人陈述 |

### 2.2 威胁、引诱、欺骗

| 方法 | 具体表现 | 法律后果 |
|:---|:---|:---|
| **威胁** | "不老实交代就抓你家人" | 供述排除 |
| **引诱** | "交代了就放你出去" | 供述排除 |
| **欺骗** | "同案犯已经交代了" | 供述排除 |

### 2.3 其他非法取证

| 情形 | 识别标准 | 法律依据 |
|:---|:---|:---|
| **单人讯问** | 讯问人员少于 2 人 | 《刑事诉讼法》第 118 条 |
| **未告知权利** | 首次讯问未告知诉讼权利 | 《刑事诉讼法》第 120 条 |
| **超期讯问** | 单次讯问超过 24 小时 | 《刑事诉讼法》第 119 条 |
| **未录音录像** | 应当录音录像而未录音录像 | 《刑事诉讼法》第 123 条 |
| **未核对确认** | 笔录未交被告人核对 | 《刑事诉讼法》第 122 条 |

## 三、非法证据排除程序

### 3.1 申请时间

| 阶段 | 申请方式 | 说明 |
|:---|:---|:---|
| **庭前会议** | 书面申请,说明线索 | **最佳时机** |
| **庭审中** | 口头或书面申请 | 法庭调查阶段 |
| **二审** | 作为上诉理由 | 一审未提出的需说明理由 |

### 3.2 申请内容模板

```
非法证据排除申请

一、申请排除的证据
   证据名称:
   证据来源:

二、涉嫌非法取证的情形
   人员:
   时间:
   地点:
   方式:

三、相关线索或材料
   1. ...
   2. ...

四、申请调查的证据
   1. 同步录音录像
   2. 入所体检表
   3. 提讯登记
   4. ...
```

### 3.3 证明责任

- **申请人**:提供涉嫌非法取证的人员、时间、地点、方式、内容等线索或材料
- **检察院**:对证据收集的合法性承担证明责任
- **法院**:对证据收集的合法性进行审查

### 3.4 法庭调查

1. **说明情况**:公诉人说明证据收集的合法性
2. **出示材料**:出示讯问笔录、提讯登记、录音录像等
3. **通知到场**:通知侦查人员或其他人员到场说明情况
4. **当庭调查**:对证据收集的合法性进行法庭调查

## 四、同步录音录像审查

### 4.1 应当录音录像的情形

- 可能判处无期徒刑、死刑的案件
- 其他重大犯罪案件

### 4.2 审查要点

| 审查项目 | 审查内容 |
|:---|:---|
| **完整性** | 是否全程不间断录制 |
| **时间** | 录制时间与笔录时间是否一致 |
| **地点** | 录制地点与笔录地点是否一致 |
| **人员** | 录制中显示的讯问人员与笔录是否一致 |
| **内容** | 录制内容与笔录内容是否一致 |
| **行为** | 是否存在刑讯逼供、威胁、引诱等行为 |

### 4.3 录音录像与笔录不一致的处理

- 以录音录像为准
- 申请排除不一致部分的笔录内容
- 申请排除全部笔录(严重不一致时)

## 五、常见非法证据排除策略

### 5.1 供述排除策略

| 策略 | 适用情形 | 操作方法 |
|:---|:---|:---|
| **体检表策略** | 入所体检有伤 | 申请调取体检表,证明刑讯逼供 |
| **时间策略** | 讯问时间异常 | 分析讯问时间,证明疲劳审讯 |
| **录像策略** | 应当录像而未录像 | 申请排除全部供述 |
| **笔录策略** | 笔录与录像不一致 | 申请排除不一致部分 |

### 5.2 证人证言排除策略

| 策略 | 适用情形 | 操作方法 |
|:---|:---|:---|
| **个别询问** | 未个别询问 | 申请调取询问笔录,证明集体询问 |
| **威胁证人** | 证人称受到威胁 | 申请证人出庭,当庭说明 |
| **引诱作证** | 证人称受到引诱 | 申请调取询问录音录像 |

## 六、"排除合理怀疑"判断方法

刑事案件证明标准为"事实清楚,证据确实、充分",达到"排除合理怀疑"。判断要点:

1. **全案证据是否形成完整锁链** —— 各证据之间能否相互印证,共同指向同一犯罪事实,无断裂、无矛盾。
2. **是否存在不能排除的其他可能性** —— 对案件事实是否还存在不能合理排除的其他解释或可能;若存在,则未达证明标准。
3. **经验法则和逻辑法则能否自洽** —— 据以定案的事实认定是否符合常识、常理、常情,推理过程有无逻辑断层或违背经验。
4. **孤证不能定案** —— 仅有被告人供述、没有其他证据印证的,不能认定有罪;任何单一证据均不足以独立支撑定罪。
