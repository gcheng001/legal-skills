# labor-policy-design — 规章制度设计/审查

## 工作定位

**职责**:**起草/审查**用工单位规章制度(典型:考勤管理制度、员工手册、奖惩条例等)。**审查模式**对齐课件2 考勤制度坑点清单 + 工时休假规则表,逐条挑坑;**设计模式**按模块生成。

**轨道**:顾问轨(轻状态:项目目录 `CLAUDE.md`+`LOG.md`+`client.md`+`deliverables/`)。

**必须确认**:是(出件前一次)。

**执行后 Hook**:否。

---

## 执行流程

### 步骤1 模式与对象判定【完成判据:模式+对象齐备】

向用户询问:
- **模式**:起草 / 审查;
- **制度对象**(可多选):①考勤管理制度 ②员工手册 ③奖惩条例 ④休假管理细则 ⑤加班管理制度 ⑥反舞弊/廉洁制度 ⑦其他。

### 步骤2 要素收集【完成判据:6项要素齐备】

询问并记录:
1. 单位基本信息(规模、岗位、行业);
2. 现存制度清单与生效版本;
3. 历史争议/判例(若有);
4. 民主程序与公示证据(是否职代会/协商/公示);
5. 特殊岗位(不定时/综合工时/外勤/销售);
6. 特殊群体(三期/工伤/病假/未成年)现有数量与覆盖情况。

### 步骤3 (审查模式)挑坑【完成判据:通用层五项硬检查 + 模块层逐条】

#### A 通用层五项硬检查(任何制度必查):

| # | 检查项 | 风险等级 |
|---|--------|---------|
| ① | **民主程序与公示证据** — 是否有职代会决议、与工会/职工代表协商的证据,签收记录 | 🟥高(否则制度无效,解雇依据崩塌) |
| ② | **经济处罚合法性** — 是否含"罚款XX元"等条款 | 🟥高(无效;改造方案:变扣为发) |
| ③ | **违纪梯度与解除衔接** — 严重违反的界定是否**量化**;一般违纪与严重违纪是否有梯度 | 🟧中 |
| ④ | **特殊工时岗位的差异化管理** — 不定时/综合工时岗位是否照搬标准工时规则 | 🟧中 |
| ⑤ | **特殊群体保护** — 三期/工伤/病假员工是否被差异化对待 | 🟥高 |

#### B 模块层挑坑(按对象选用):

| 对象 | 主要参考 |
|------|---------|
| 考勤管理制度 | 9大坑(参见 `考勤制度坑点清单.md`):罚款、旷一扣三、1元/分钟、试用期年假、试用期病假、婚假限年等 |
| 加班管理制度 | (1)审批vs支付的灰区; (2)周末加班调休逾期作废的无效风险; (3)出差不计加班的争议 |
| 休假管理细则 | 法定假期 vs 福利假期的差异;育儿假/陪护假是否覆盖;年假逾期作废 |
| 奖惩条例 | 严重违纪的界定应量化;不得把法定权益列为违纪;经济处罚仅以扣减考核为限 |
| 员工手册 | 五项硬检查 + 上述模块的并集;尤其注意"病假=事假""试用期不享年假"等条款 |

#### C 输出 `deliverables/制度审查意见.md`,表格:

| 制度/章节 | 条款位置 | 风险点 | 权威层级标注 | 修改建议 | 风险等级 |
|---------|---------|--------|-------------|---------|---------|
| 考勤 §3.1.2 | "罚款1元/分钟" | 浙江解答(六)第3条 + 实质 | 🟥高 | 删除"罚款"字样或改为考核扣绩效 |

**完成判据**:所有模块的逐条款 100% 有结论("无问题"也要显式记录)。

### 步骤3 (设计模式)按模块生成【完成判据:六模块逐项生成】

按用户指定模块生成,每模块至少包含:
1. 立法目的;
2. 适用范围;
3. 程序合法性条款(民主程序 + 公示);
4. 具体规则(用"软条款"变扣为发,而非"硬条款"罚款);
5. 与现有制度的衔接条款;
6. 生效与修订条款。

**模块清单**:
- 工时制度;
- 考勤打卡;
- 请假审批;
- 加班管理;
- 假期管理(法定 + 福利);
- 违纪处理(梯度化)。

⚠️ 设计模式特别强调:
- **罚款 = 全禁**,给出的所有制度条款用"考核扣减"或"全勤奖"逻辑;
- **试用期 = 全享**,年假/病假不能因试用期歧视;
- **婚假/产假/陪护假 = 法定**,不与是否转正挂钩,不设"一周年内休完"等限制。

### 步骤4 通用文档包存与确认【完成判据:文档包完整】

包存 `deliverables/`。
md2word 仅用户确认后触发。

## 红线

引用 `labor-os/references/redlines-labor.md`,本skill特有补充:
1. **罚款条款零容忍红线**:任何含"罚款XX元""扣X倍"的条款 → 出**🟥高风险标**;
2. **试用期歧视零容忍红线**:试用期内不享年假/病假按事假 → 出**🟥高风险标**;
3. **民主程序证据红线**:无民主程序证据 → 制度无效 → 解除依据崩塌,出**🟥高风险标**;
4. **浙江口径标注红线**:逐条标"依浙江口径";
5. **量化红线**:严重违纪界定应**量化**或举例,不可"以公司认定为准"等模糊条款。
