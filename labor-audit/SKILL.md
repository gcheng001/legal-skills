# labor-audit — 用工体检(编排器)

## 工作定位

**职责**:**编排器**——不重写各 skill,而是依次调用 `labor-contract-design`(审查模式)、`labor-policy-design`(审查模式)核心检查逻辑,外加**社保/工时/离职**三个专项扫描,汇总为一份**用工体检报告**(红黄蓝三级风险 + 整改优先级排序 + 整改依据与成本估算)。

**轨道**:顾问轨(轻状态:项目目录 `CLAUDE.md`+`LOG.md`+`client.md`+`deliverables/`)。

**必须确认**:是(出体检报告前一次)。

**执行后 Hook**:否。

---

## 执行流程

### 步骤1 接收委托 + 资料收集【完成判据:六类资料齐备】

询问并收集:
1. 单位基本信息(规模、行业、岗位分布);
2. **现行劳动合同样本**(可多份);
3. **现行规章制度清单**(员工手册、考勤、奖惩、薪酬等);
4. **社保缴纳情况**(基数、险种、参/未参保);
5. **工时制度审批文件**(不定时/综合工时审批文号);
6. **离职管理档案**(近12个月的离职清单 + 离职手续样本)。

### 步骤2 调用子检查 + 专项扫描【完成判据:六模块逐一有结论+证据索引】

#### A 调用子skill核心检查

| 模块 | 调用 | 重点抽取 |
|------|------|---------|
| ① **合同签订** | `labor-contract-design` 审查模式 | 13条款域中"违法无效"或"必败诉"项 |
| ② **规章制度** | `labor-policy-design` 审查模式 | 五项硬检查:民主程序/公示/罚款/量化/特殊群体 |

#### B 专项扫描(本skill独立执行)

| 模块 | 扫描要点 |
|------|---------|
| ③ **工时与加班** | (a) 工时制是否经审批;(b) 加班审批制度是否有"阻断支付"的违反;(c) 出差/培训/党建活动不计加班的合理性 |
| ④ **社保** | (a) **放弃社保承诺无效**(司法解释二第19条)的核查;(b) 缴费基数合规性;(c) 工伤异地参保处理 |
| ⑤ **假期执行** | (a) 法定假期(婚/产/护理/育儿/陪护)是否齐全;(b) 年假标准与试用期年假;(c) 病假待遇 |
| ⑥ **离职管理** | (a) **5日内结清工资**(浙江);(b) 离职证明出具;(c) 竞业启动;(d) 经济补偿金核算 |

### 步骤3 汇总输出【完成判据:分级报告+整改优先级】

输出 `deliverables/用工体检报告_XX公司.md`,结构:

#### 第一部分 执行摘要
- 单位名称 / 检查日期 / 范围;
- 风险点总数(🟥N / 🟧N / 🟨N);
- 整改优先级 P0/P1/P2。

#### 第二部分 分模块报告

每模块使用统一结构:
| 检查项 | 现状描述 | 风险点 | 依据 | 整改建议 | 成本估算 | 风险等级 | 整改优先级 |
|--------|---------|--------|------|---------|---------|---------|----------|

#### 第三部分 整改优先级排序

| P0 | 7天内整改 | (🟥高风险项)— 列举 |
| P1 | 30天内整改 | (🟧中风险项) |
| P2 | 季度内整改 | (🟨低风险项 + 优化建议) |

#### 第四部分 风险与整改预算估算

- **最高应急预算**(P0 整改期可能的人员/律师/补偿成本);
- **中位预算**(P1 整改);
- **远期优化预算**(P2)。

### 步骤4 内部审阅与确认【完成判据:用户确认+文档包存】

包存 `deliverables/`。

报告**不外传**(给单位内部 HR+法务+老板);
如需对外(如向董事会汇报),由用户在确认基础上导出节选版本。

## 红线

引用 `labor-os/references/redlines-labor.md`,本skill特有补充:
1. **编排而非替代红线**:**不重写**子skill的检查逻辑,**只调用+汇总**;
2. **整改优先级红线**:🟥高风险 = P0 (7天内),不得推迟到 P1;
3. **浙江口径标注红线**:浙江口径条款逐条标"依浙江口径";
4. **方案不唯红线**:任何"建议 缴纳社保/补发加班费/补发年假"的整改建议,必须给出**具体计算式或方案**,不写空话;
5. **避免恐慌红线**:报告应**聚焦整改路径**,避免让单位"恐慌式整改"(否则 hr 离职等问题),整改优先级和缓急应明示。
