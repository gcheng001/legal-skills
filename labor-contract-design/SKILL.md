# labor-contract-design — 劳动合同设计/审查

## 工作定位

**职责**:**起草模式**(从要素出发生成13条款域完整的合同);**审查模式**(对客户既有合同逐域挑坑,风险分三级);两者共用同一13条款域框架。

**轨道**:顾问轨(轻状态:项目目录 `CLAUDE.md`+`LOG.md`+`client.md`+`deliverables/`,无 hook 无 state.json)。

**必须确认**:是(出件前一次)。

**执行后 Hook**:否。

---

## 执行流程

### 步骤1 模式判定【完成判据:任一模式选定+要素收集启动】

向用户出示:
- **1 起草模式**:从要素出发生成合同;
- **2 审查模式**:对客户合同逐域挑坑;

后续按选定模式执行。

### 步骤2 要素收集【完成判据:11项要素齐备+特殊主体识别】

询问并记录(起草模式必需;审查模式按需):
1. 用人单位(全称、统一社会信用代码、注册地、经营范围、行业);
2. 劳动者(姓名、年龄、身份证号——审查模式可省);
3. 岗位 / 部门 / 报告对象;
4. 工作地点(省级/市级);
5. 合同期限 + 试用期(月数);
6. 工时制(标准/不定时/综合计算,需确认是否已审批);
7. 薪酬结构(固定工资 + 绩效 + 年终奖 + 加班费基数);
8. 是否涉及商业秘密 / 竞业限制;
9. **年龄是否超过法定退休年龄或已提前退休** — 触发 2026 新规切换;
10. 是否特殊群体(三期/工伤/医疗期);
11. 用工形式(直接雇佣/劳务派遣/借调/关联公司)。

### 步骤3 (起草模式)按13条款域逐域生成【完成判据:13域无一跳过,每域批注设计理由】

| 域 | 标题 | 必含点 |
|---|------|-------|
| 1 | 保证与陈述 | 信息真实性 + 不负竞业 + 未建立劳动关系 + 调岗权利约定 |
| 2 | 合同类型与期限 | 三类合同选其一;试用期约定;无固定续订风险提示 |
| 3 | 工作内容与地点 | 岗位/部门;宽口径或窄口径约定 |
| 4 | 工时与休假 | 工时制 + 加班审批制度 + 年假标准;特殊工时未审批风险 |
| 5 | 报酬与支付 | 工资结构四要件 + 加班费基数明确;年终奖离职条款 |
| 6 | 社保与福利 | 5项保险 + 异地参保约定(若适用);放弃社保条款无效声明 |
| 7 | 劳动保护 | 职业病危害告知 + 防护义务;不得因此解除条款 |
| 8 | 变更/解除/终止 | 变更书面 + 1个月履行例外 + 解除梯度;5日结清(浙江) |
| 9 | 竞业与保密 | 适用人范围 + 2年上限 + 补偿 + 范围界定;商业秘密载体范围 |
| 10 | 违约责任 | 劳动者三种赔偿责任 |
| 11 | 争议处理 | 一裁二审 + 一裁终局三类提示 + 管辖约定 |
| 12 | 其他约定 | 通知地址 + 个人信息使用授权 + 异议期 |
| 13 | **超龄人员**(若适用,自动切换为"用工协议") | 6项必含点;签署用工协议标题 |

**特殊主体自动切换**:
- **超龄劳动者**:起草模式自动切换为"用工协议",标题、命名、关键条款按 2026 人社部令 56号第六条准备;
- **草案提示**:起草结果必须在每域批注"设计理由 + 坑点规避"。

**输出**:`deliverables/劳动合同_XX公司_XX.md`(Markdown,可由 md2word 转 docx)。

### 步骤3 (审查模式)按13条款域逐域挑坑【完成判据:13域无一跳过,风险分三级】

读客户合同 → 13域逐域对照 `合同条款设计要点.md` + `主体资格坑点清单.md` + `浙江口径汇编.md`:

输出 `deliverables/合同审查意见.md`,表格:
| 条款位置 | 风险点 | 权威层级标注的依据 | 修改建议文本 | 风险等级 |

**三级风险**:
- 🟥 **高**:违法无效或必败诉(必须修改);
- 🟧 **中**:口径不利(建议修改);
- 🟨 **低**:优化建议(可选)。

**完成判据**:13域全部有结论(即便"无问题"也要显式记录)。

### 步骤4 文档包存与确认【完成判据:文档包完整】

包存 `deliverables/`。
md2word 仅用户确认后触发。

## 红线

引用 `labor-os/references/redlines-labor.md`,本skill特有补充:
1. **超龄切换红线**:劳动年龄达法定退休年龄或已提前退休 → 起草必须生成"用工协议"而非"劳动合同";
2. **浙江口径标注红线**:引用浙江条款逐条标"依浙江口径";
3. **坑点不掩盖红线**:审查模式下,即便客户要求"只挑主要的",仍必须**13域全过**(完成判据);
4. **禁止仅写"建议协商一致变更"等空话红线**:每条修改建议必须可落字。
